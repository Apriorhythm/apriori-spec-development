## Contract (code-is-truth)

source-commit: 024ee2c

**Responsibility.** Merge a change's delta spec into the living store by stable Requirement ID (STEP6 archive action); move the change dir to `changes/archive/`. Zero deps. 3.1: also the home of the merge-family pure helpers shared with `verify --change` — delta discovery, projection building, CAS base stamps, realpath containment — plus the high-level `archive --change` transaction and the `stamp` subcommand.

**Delta format.** `## ADDED|MODIFIED|REMOVED|RENAMED Requirements` (h2 sections) containing `### Requirement: <name>` blocks (h3); RENAMED carries `- Old -> New` lines; optionally ONE CAS stamp line `<!-- apriori-base: sha256:<64hex> | new -->` before the first section. Parsing: `parseDeltaStrict(text)` → `{ delta, stamp, problems[] }` — duplicate requirement names (within/across sections) and stamp problems surface as problems; `parseDelta(text)` = its delta only; `parseRequirementsStrict(text)` → `{ map, duplicates[] }` (first block wins, duplicates reported); `parseRequirements` = its map; `deltaOpCount(delta)` → total parsed ops (0 = no recognized section OR recognized sections with no parseable requirement/rename lines). `parseStamp(text)` → `{ stamp, problems }` — any standalone comment line ATTEMPTING apriori-base that fails the strict form is a problem, never silently 'unstamped'. `fingerprint(text)` → `sha256:<64hex>` over CRLF/CR→LF-normalized content.

**Public interface.**
- `merge(storeText, delta, change)` — PURE. → `{ store:Map, merged, modified, deprecated, renamed, conflicts, unchanged }`. Duplicate requirement names in the STORE text → conflicts (corruption guard). Order of application: RENAMED first (in-place key swap preserving document order), then ADDED, MODIFIED, REMOVED.
  - ADDED on existing name: identical trimmed content → `unchanged` (idempotent rerun no-op) UNLESS the name was created by this run's RENAMED (`renamedTargets`) → conflict.
  - MODIFIED replaces the whole block; missing target → conflict.
  - REMOVED keeps the block, injects `_deprecated (superseded by <change>)_` into the heading line.
  - RENAMED with source gone + target present → `unchanged` ("already renamed" rerun signature); source gone + target absent → conflict; target already exists → conflict.
  - REMOVED with target gone but `<name>  _deprecated (superseded by <THIS change>)_` present → `unchanged` ("already deprecated" rerun signature); deprecated by a DIFFERENT change → conflict.
  - ANY conflict → nothing written (CLI exit 1).
- `renderStore(storeText, store)` — preserves the store's header (text before the first `### Requirement:`), then blocks joined with `\n`.
- `archiveStamp(d)` → `YYYY-MM-DDThhmm` (colon-free, CLI clock).
- `CHANGE_NAME_RE` = `/^[a-z0-9]+(-[a-z0-9]+)*$/` (same rule as `apriori new`).
- `archiveChangeDir(changesDir, name, now, ops?)` — validates name; realpath containment on BOTH source and destination (a symlinked `archive/` pointing outside is rejected before any move); `renameSync` (via ops when given) to `changes/archive/<stamp>-<name>/`; returns dest or null when source missing; throws on invalid name/escape.
- `containsReal(root, target)` — realpath containment; not-yet-existing targets judged by nearest existing ancestor; STRICT (root itself is not inside root); fail-closed on unreadable paths.
- `discoverDeltas(changesDirAbs, name)` → `{ files:[{abs,suffix}], errors[] }` — validates name (CHANGE_NAME_RE), change-dir existence + containment, specs/ itself containment-checked before becoming a root (symlinked specs/ rejected); walk follows symlink dirents explicitly (escaping links = errors, never silent skips). Errors are VALIDATION class → exit 2 on both surfaces.
- `buildProjection(storeRoot, deltaFiles, change)` → `{ texts:Map<suffix,text>, modules, perModule, conflicts, casMismatches, hygiene, validation }` — all store files pass through; each delta strict-parsed, CAS-checked, merged in memory; nothing touches disk.

Mixing --change with only one of --store/--delta → exit 2. Exit: 0 merged/no-op · 1 conflict/CAS/hygiene/zero-op/stage/commit/move-failure/pre-existing-temp · 2 usage/invalid name/missing change dir/containment.

**Transactional write ordering (`--write`).** store staged to `<store>.tmp-archive` → dir move (atomic rename) → store committed via `renameSync(tmp, store)`. Move failure → tmp discarded, store byte-for-byte untouched. # Requirement — gate-command (v1)

change: gate-command
target lineage: **v3 branch** (never merge to main or v2). Ships in apriori-cli **3.2.0-line work started as 3.1.x feature** — versioning decided at release; no compatibility impact (purely additive subcommand).

## Background — the problem (current state A)

The runbook's exit conditions for a change are individually machine-checkable — `verify` GREEN, tasks.md all `[x]`, a legal flow-state, a ledger with no open rows, every `VERDICT:` line backed by a raw archive (§1 enforcement layer ①), fresh KB stamps — but no command aggregates them. Today an agent (or a CI job, or a human at gate ④) assembles the picture by hand from five artifact formats. The verdict-evidence check in particular ("every verdict line must have a matching raw archive — a mechanical backstop against simulated reviews") exists only as prose; nothing enforces it.

Since 3.1.0, the binding gate has two forms (projected `verify --change` mid-change, plain `verify --specs` post-archive) — picking the right one is itself a rule an aggregator should encode.

## Goal (target state B)

`apriori gate --change <name>` — one read-only command, one exit code, aggregating the machine-checkable gate conditions for one change. It reuses the existing parsers and gates (status's flow-state/ledger parsers, spec-runner's verify, archive-merge's discovery) — it invents no new semantics.

**Explicitly NOT a human-gate substitute:** `GATE: PASS` means the mechanical face is clean; protected human gates (KB sign-off, shrink, intent-card) remain human. The output states this in one line.

## The checks

Stage resolution first: the change dir is looked up at `apriori/changes/<name>/` (**in-flight**) or, failing that, at the newest `apriori/changes/archive/<stamp>-<name>/` (**archived** — the gate-④-pending window). Found in neither → exit 2. All later checks read from the resolved dir.

- `formatOne(s)`, `toJson(s)` — human/machine shapes.
- `cli(argv)`: `[--change <name>] [--json]`; root = process.cwd(). Without `--change`: list actives. Always exit 0 (status never fails the build).

**Pitfalls.**
- `changeStatus` looks ONLY under `apriori/changes/<name>` — it does NOT find archived changes under `changes/archive/<stamp>-<name>/` (relevant while gate ④ is pending post-move).
- `parseFlowState` strips ` # comment` from values — a next-action containing a literal `#` would be truncated.
- `parseLedger` matches any `| a | … | b |` row shape — prose tables in the same file would be picked up too (ledger files carry only the one table by convention).
- Placeholder values (`<trivial | medium | large>`) parse as ordinary strings — callers must detect unfilled skeletons themselves.

'use strict';
/*
 * apriori status — answer "where am I / what's left" for a change.
 * Reads the flow-state file + the issue ledger; zero deps, pure Node stdlib.
 */
const fs = require('fs');
const path = require('path');

// parse `key: value` lines from a flow-state file → object; plus the last gate line
function parseFlowState(text) {
  const out = {};
  for (const key of ['change', 'tier', 'track', 'current-step', 'round', 'next-action', 'lineage']) {
    const m = text.match(new RegExp('^' + key + ':\\s*(.+)$', 'm'));
    if (m) out[key] = m[1].replace(/\s*#.*$/, '').trim();
  }
  const gates = [...text.matchAll(/^\s*-\s*(\d{4}-\d{2}-\d{2}\S*\s+.+)$/gm)].map((m) => m[1].trim());
  out.lastGate = gates.length ? gates[gates.length - 1] : null;
  return out;
}

// parse a P0 ledger markdown table → rows with {id, status}
function parseLedger(text) {
  const rows = [];
  for (const line of text.split('\n')) {
    const m = line.match(/^\|\s*([^|]+?)\s*\|.*\|\s*([^|]+?)\s*\|\s*$/);
    if (!m) continue;
    const id = m[1].trim(), status = m[2].trim();
    if (id === 'ID' || /^-+$/.test(id)) continue;         // header / separator
    rows.push({ id, status });
  }
  return rows;
}

function activeChanges(root) {
  const dir = path.join(root, 'apriori', 'changes');
  if (!fs.existsSync(dir)) return [];
  return fs.readdirSync(dir, { withFileTypes: true })
    .filter((e) => e.isDirectory() && e.name !== 'archive')
    .map((e) => e.name).sort();
}

function changeStatus(root, change) {
  const fsPath = path.join(root, 'apriori', 'changes', change, 'flow-state.md');
  const state = fs.existsSync(fsPath) ? parseFlowState(fs.readFileSync(fsPath, 'utf8')) : null;
  const ledgerPath = path.join(root, 'apriori', 'review', `${change}-issues.md`);
  const rows = fs.existsSync(ledgerPath) ? parseLedger(fs.readFileSync(ledgerPath, 'utf8')) : [];
  const open = rows.filter((r) => /^open\b/i.test(r.status));
  return { change, state, open, hasFlowState: !!state };
}

function formatOne(s) {
  const lines = [];
  if (!s.state) { lines.push(`change: ${s.change} (no flow-state file found)`); }
  else {
    lines.push(`change:       ${s.state.change || s.change}`);
    lines.push(`step:         ${s.state['current-step'] || '?'}   (tier ${s.state.tier || '?'}, track ${s.state.track || '?'})`);
    if (s.state['next-action']) lines.push(`next-action:  ${s.state['next-action']}`);
    if (s.state.lastGate) lines.push(`last gate:    ${s.state.lastGate}`);
  }
  lines.push(`open ledger:  ${s.open.length}` + (s.open.length ? ` — ${s.open.map((r) => r.id).join(', ')}` : ''));
  return lines.join('\n');
}

// machine-consumable shape for one change
function toJson(s) {
  return {
    change: s.change,
    step: s.state ? s.state['current-step'] || null : null,
    tier: s.state ? s.state.tier || null : null,
    track: s.state ? s.state.track || null : null,
    lineage: s.state ? s.state.lineage || null : null,
    nextAction: s.state ? s.state['next-action'] || null : null,
    lastGate: s.state ? s.state.lastGate : null,
    hasFlowState: s.hasFlowState,
    openLedger: s.open.map((r) => r.id),
  };
}

function cli(argv) {
  const root = process.cwd();
  let change = null, json = false;
  for (let i = 0; i < argv.length; i++) {
    if (argv[i] === '--change') change = argv[++i];
    else if (argv[i] === '--json') json = true;
  }
  if (change) {
    const s = changeStatus(root, change);
    console.log(json ? JSON.stringify(toJson(s), null, 2) : formatOne(s));
    return 0;
  }
  const changes = activeChanges(root);
  if (json) {
    console.log(JSON.stringify({ changes: changes.map((c) => toJson(changeStatus(root, c))) }, null, 2));
    return 0;
  }
  if (!changes.length) { console.log('No active changes under apriori/changes/.'); return 0; }
  console.log(`Active changes (${changes.length}):\n`);
  for (const c of changes) {
    const s = changeStatus(root, c);
    const step = s.state ? s.state['current-step'] || '?' : 'no flow-state';
    console.log(`  ${c}  —  ${step}, ${s.open.length} open`);
  }
  console.log('\nRun `apriori status --change <name>` for detail.');
  return 0;
}

module.exports = { parseFlowState, parseLedger, activeChanges, changeStatus, formatOne, toJson, cli };
