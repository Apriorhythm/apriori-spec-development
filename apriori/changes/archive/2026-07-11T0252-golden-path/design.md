# Design — golden-path

scripts/golden-path.mjs (ESM, stdlib): `export function extractBlocks(text)` — regex over the Quickstart section (## Quickstart → next ##), ```shell fences; `export function buildPlan(blocks, mode, opts)` — returns {script, expects:[0,1,0,0]}. ONE RESOLVER RULE (GPSPEC-3): both modes produce a `binDir` that is prepended to PATH, and that SAME env is used for the block walk AND every final-state assertion — no bash functions, no per-call aliasing:
- local: the runner writes a `binDir/apriori` shim (`#!/bin/sh` + `exec node "<abs checkout>/bin/apriori.js" "$@"`, chmod 755);
- packed: block 1's `npm i -g apriori-cli` line becomes `npm i -g "<tgz>" --prefix "<prefixDir>"`; binDir = the npm global bin dir under the prefix (POSIX `<prefix>/bin`, Windows `<prefix>`).
Preflight (both modes, IN BASH so path forms are bash-native, GPSPEC-4): `BD="$(cd "<binDir>" && pwd)"; case "$(command -v apriori)" in "$BD"/*) ;; *) echo "apriori resolves outside the expected binDir"; exit 90;; esac` — `cd && pwd` normalizes the Windows drive form to what `command -v` returns under Git-bash; no cygpath dependency. Runner: write the assembled bash script to a temp file (heredoc-safe); the script runs WITHOUT `set -e` so a documented non-zero (block 2's red verify) never aborts the walk — after each block's last line an `echo __BLOCK_N_EXIT=$?` sentinel captures the code; the runner parses stdout for ALL sentinels (a missing sentinel = the script itself died = failure naming the last block seen) and compares against expects. main(): parse --local/--packed, tmpdir, run, assert per-block sentinels; final-state assertions run through the SAME medium and env as the walk (`bash -c 'apriori …'` with the binDir-prepended PATH, cwd = the demo dir) — a test proves a bogus global `apriori` earlier on the ORIGINAL PATH is never picked up; exit non-zero naming failures.

ci.yml: add job golden-path {matrix os [ubuntu-latest, windows-latest], node 20, shell bash}: checkout → setup-node → `TGZ=$(npm pack --silent)` → `node scripts/golden-path.mjs --packed "$TGZ"` — npm pack prints the exact filename; no glob ambiguity (GPSPEC-2).

test/golden-path.test.js: GP-01 extractor on real README (4 blocks, order) + pure (no fs); GP-04 doctored text (3 blocks / reordered) → buildPlan/assert fails naming block; GP-02/03 one --local spawn of the script (~10s). GP-05 binds via a test that asserts buildPlan(packed) contains the prefix/PATH/preflight lines (the real packed run lives in CI — its scenario binding is the plan-construction test + the CI job; recorded in tasks as the D-SR-4-style layered exit condition).
