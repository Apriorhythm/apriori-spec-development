# Design — ledger-states

**lib/gate.js — `checkLedger(cwd, name, tier, stage, dir)`** (two new params: gate's resolved stage + change dir; the one call site passes `loc.stage`/`loc.dir`):
- Status classifier (leading token, case-insensitive): `const m = /^(open|fixed|verified|rejected-verified|rejected|advisory-acked|waived)\b/i.exec(r.status)` — NOTE `rejected-verified` alternated BEFORE `rejected` (alternation order, the delta-consumption lesson class). No match → block `«status» is not in the ledger vocabulary` (both stages).
- Reason rule extended: `rejected`, `rejected-verified`, `waived` all require a word char after the token (reuse the existing strip-and-test).
- `waived` evidence (LSSPEC-2: SAME-ENTRY matching): read `flow-state.md` from the change dir (same file C3 reads; gate already has `dir`), extract the `gates:` block (from /^gates:/m to EOF or the next TOP-LEVEL key — an unindented /^[A-Za-z][\w-]*:/ line; indented gate bullets with timestamps/colons are entries, not keys), split it into ENTRIES (lines starting /^\s*-\s/; a continuation line without the dash belongs to the previous entry), and require AT LEAST ONE single entry to contain BOTH the row ID as an EXACT TOKEN — new RegExp(`(^|[^A-Za-z0-9-])${escapeRe(id)}([^A-Za-z0-9-]|$)`) so LS-1 never matches inside LS-10 (LSSPEC-3; escapeRe = the standard replace(/[.*+?^${}()|[\]\\]/g, '\\$&')) — and /waiv/i; the ID in one entry and 'waived' in another never passes. GT-14 gains the subcase: row LS-1 with a gates entry waiving LS-10 blocks. Missing → block `«ID» is waived without a gates: entry recording the human decision`.
- Stage rules: `open` blocks (both); archived additionally blocks `fixed` (`fixed but never verified — reviewer must verify, or the human waives it`) and plain `rejected` (`rejected without reviewer concurrence — flip to rejected-verified, or the human waives it`).
- Cure messages content-tested (/reviewer must verify/, /reviewer concurrence|rejected-verified/, /gates: entry/), not exact strings.

**Corpus test (GT-15)** in test/gate.test.js: walk `apriori/changes/archive/*` (skip-if-absent), derive name by stripping the fixed stamp prefix /^\d{4}-\d{2}-\d{2}T\d{4}-/, for each existing `apriori/review/<name>-issues.md` run the same classifier + terminal check + REASON FLOOR (reasonless rejected-verified/waived fail the corpus too — LSSPEC-ADV-1). Export a small pure `classifyStatus(status)` from gate.js returning {legal, terminal, needsReason, hasReason, isWaived} so gate and the corpus test share one classifier.

**Migration** (T3): apriori/review/update-manifest-issues.md UMIMPL-1 → `rejected-verified — refuted with reproduction evidence: the TOOLS loop has no existence pre-check and the missing row IS emitted (UP-10b); reviewer concurred (impl-review-v2)`.
