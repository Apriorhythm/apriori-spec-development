# Design — req-sweep

**lib/archive-merge.js — `archiveChange` phase 4, new staging step between commit and move** (changesDirExplicit && write only):
- `const reqDir = path.resolve(cwd, 'requirement')`; absent → skip. Present → `containsReal(cwd, reqDir)` else abort (staging taxonomy below).
- Patterns: `const esc = escapeRe(o.change)` — a LOCAL dependency-free escapeRe in archive-merge.js (RSSPEC-1: managed.js requires archive-merge, so importing managed from here would cycle; a 1-line local copy beats a cycle) → three RegExps `^${esc}-req-v[0-9]+\.md$`, `^${esc}-req-final\.md$`, `^${esc}-intent-card\.md$`.
- Scan `fs.readdirSync(reqDir, { withFileTypes: true })`; for each entry whose name matches any pattern: `lstatSync` — symlink → abort naming it + cure (replace with a regular file or remove, then rerun); regular file → candidate. Non-matching entries ignored (symlinks included).
- Candidates non-empty → `const stageDest = path.join(changesDir, o.change, 'requirement')`; `containsReal(changesDir, stageDest)` else abort; mkdir; per file `ops.renameSync(src, dest)` (the DI seam — M5 injection point); any throw → abort.
- Abort = `err.push('archive: stores committed but requirement staging failed: <file/reason> — rerun to complete')`, exit 1, BEFORE archiveChangeDir. Rerun completes: stores hit rerun-repair/no-op, already-staged files absent from reqDir, move retries.
- Success with n>0 → `out.push('staged: <n> requirement file(s) → changes/<name>/requirement/')` before the move; the move then carries them.
- Zero candidates → nothing (AM-39).
