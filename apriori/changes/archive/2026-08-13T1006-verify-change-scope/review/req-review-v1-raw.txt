## 目标（目标态 B）

### B1. `verify --change <name>` 的 verdict 收窄为"本 change 达标"

- **change 范围**定义（在既有投影之上，投影机制不变——merge 冲突/CAS/hygiene 检查全保留）：

- **verdict（exit 0/1 的判据）只看 change 范围**：本 change 每个场景 ≥1 个 passing 测试、无 red、（change 范围内）无 duplicate、delta 内无 unidentified → GREEN。

# TRUTH — spec-runner (`lib/spec-runner.js`, CLI subcommand `verify`)

## Contract (code-is-truth)

source-commit: d7d65d3

**Responsibility.** Bind spec scenario IDs to a TAP-emitting test run; report per-scenario red/green; act as STEP5's deterministic gate. Fail-closed: a broken or vacuous run is never GREEN. 3.1: `--change <name>` verifies against the in-memory PROJECTED store (archive's merge() applied to the living store) — the mid-change form.

**Public interface (module exports).**
- `leadId(text, idRe)` → leading ID or null. Word-boundary strict: `XX-01b`, `XX-01_x` are NOT `XX-01`.
- `stripFences(text)` → text with ``` fenced blocks removed (fenced scenarios are documentation, not spec).
- `mdFiles` is internal; `collectScenarios(specTargets, idRe)` → `{ byId, unidentified:[[file,title]], files, missingTargets, duplicates:[{id,files}] }`. A target may be a dir (recursed for `*.md`, sorted) or a single file (accepted as-is, ANY extension); dedupes overlapping targets. Scenario discovery matches exact h4 lines `#### Scenario: …` only. Scenarios inside DEPRECATED requirement blocks (heading carries `_deprecated (superseded by …)_`) are excluded in EVERY form — not demanded, not listed; their lingering tests turn ORPHAN.
- `collectScenariosFromTexts(Map<label,text>, idRe)` — same scan over in-memory texts (the projection path); labels are store-relative suffixes.
- `parseTap(out, idRe)` → `{ results: Map<id,{pass,fail,skip}>, untagged:[], untaggedFails, bailout, plans:number[], points, dupNumbers:number[] }`. Only lines shaped exactly `ok|not ok <n> - <name>` BIND — a TAP result line without the ` - ` separator produces no binding. Since tap-plan (3.3.x) a per-line pre-pass (one trailing `\r` stripped) additionally collects: `plans` = every top-level `1..N` (trailing `# SKIP`/`# TODO` directive legal, N still parses); `points` = count of top-level result tokens `/^(?:ok|not ok)(?:\s|$)/` (bare/unnumbered points count; `ok:`-prefixed and indented lines never do); `dupNumbers` = complete numeric point tokens (`ok 1abc` stays unnumbered) seen more than once, numerically. `# SKIP`/`# TODO` counts as skip (proves nothing); untagged `not ok` without directive increments `untaggedFails`; `Bail out!` line captured.
- `zeroTapParsed(out, results, untagged)` → true when output exists but no TAP line parsed AND no `TAP version`/`1..N` plan line (plan line = TAP reporter with an empty suite, not a reporter problem).
- `runTestCommand(cmd, cwd)` → `{ out (stdout+\n+stderr), status (null if signal-killed), signal, error }` via `spawnSync(shell:true)`.
- `evaluate(byId, unidentified, results)` → `{ boundGreen, boundRed, unbound, orphan, unidentified, clean }`. A scenario whose only results are skips is UNBOUND.
- `verify(opts {specs:[], change, testCmd, idPattern, cwd})` — with `change`: builds the projection via archive-merge's discoverDeltas/buildProjection (roots `<cwd>/apriori/{changes,specs}`); ANY projection failure (validation/hygiene/CAS/merge-conflict) → run with `errors` set and NO test executed; success → normal pipeline over projected texts; run gains `projection: {change, modules, conflicts}`. Without `change`: unchanged. → run object `{ verdict, results, fileCount, failCount, scenarioCount, missingTargets, duplicates, bailout, noTap, exec{status,signal,error}, errors }`. `failCount` = tagged fails + `untaggedFails`.
- `infraErrors(run)` → string[] (empty = trustworthy). Triggers: missing spec target · zero spec files · zero scenarios · spawn error · signal kill · bailout · zero-TAP-parsed · plan trio (defensive defaults keep legacy run shapes valid: multiple top-level plans → error naming the cure; exactly one plan and plan ≠ points → truncated/garbled; exactly one plan and duplicate point numbers) · non-zero exit with `failCount === 0` (TAP picture doesn't explain the exit). Gate surfaces any of these as ERROR exit 2 (`verify: <msg>`), outranking a C1 binding block; doctor's probe classification intentionally does not consume infraErrors.
- `formatReport(...)` → human report; RESULT line: `ERROR — run not trustworthy (see stderr)` / `GREEN — spec is the test suite` / `GAPS`. Duplicates block GREEN.
- `verifyJson(run)` → `{ clean, result: GREEN|GAPS|ERROR, errors, specFiles, exec, duplicates, boundGreen[], boundRed[], unbound[], orphan[], unidentified[] }`; `--change` runs add exactly one field `projection: {change, modules, conflicts}` — never present otherwise. Since cas-enforcement (3.3.x): `--change` runs carry `projection.unstampedMutations` (suffixes, `[]` when none) + `projection.notes`; the cli prints one stderr warning per unstamped mutation delta — verdict untouched (WARN grade).
- `configTestCmd(cwd)` → test-cmd from `apriori/process-config.md`'s `| test-cmd | … |` row, or null.
- `cli(argv)` → exit code via the shared strict parser (truth/args.md): --help exits 0; unknown flags/stray positionals exit 2. `--specs <dir...>` OR `--change <name>` (mutually exclusive) `--test-cmd "<cmd>" [--id-pattern] [--cwd] [--json]`; test-cmd falls back to config row. Exit: 0 GREEN · 1 gaps/duplicates · 2 infra/usage error, incl. all projection failure classes.
- `DEFAULT_ID` = `[A-Z]+-\d+`.

**Data flow.** spec targets → collectScenarios → run test cmd once → parseTap → evaluate → infraErrors → report/JSON. One test-command invocation per verify run; no state persists between runs (stateless, reads FS + spawns only).

**Three moments.** No external shared state. FS reads only; the spawned test command is the only side effect.

**Pitfalls.**
- `--specs` consumes following args until the next `--` flag — a path starting with `--` is impossible.
- A direct-file `--specs` target is read whatever its extension; only directory recursion filters to `.md`.
- `exec.status` is null when signal-killed; the non-zero-exit rule explicitly guards `status !== null`.
- Requires `./archive-merge` (one-way: archive-merge never requires spec-runner).

// Leading scenario/test ID. The match must end at a word boundary: `XX-01b` is NOT `XX-01` —
// silently truncating would merge two different scenarios into one binding.
function leadId(text, idRe) {
  const m = text.trim().match(idRe);
  if (!m || m.index !== 0) return null;
  const next = text.trim()[m[0].length];
  if (next !== undefined && /[A-Za-z0-9_]/.test(next)) return null;
  return m[0];
}

function stripFences(text) { return text.replace(/```[\s\S]*?```/g, ''); }

// ---- the id matcher: one recognition contract, two execution channels -------------------
// A config-sourced pattern is repository input that CI consumes automatically; its every
// actual application runs inside a terminable child (SIGKILL on budget) so a catastrophic
// pattern can never hang the CLI. Flag/default origins are operator/built-in trust: inline.
const CHILD_PATH = path.join(__dirname, 'id-match-child.js');
// the child's spawn contract, exported so tests assert the budget DETERMINISTICALLY
// (a wall-clock window cannot prove the 2000ms figure)
const CHILD_SPAWN_OPTS = Object.freeze({ timeout: 2000, killSignal: 'SIGKILL', shell: false });
let childRunnerOverride = null;                 // test seam — SR-55 injects failures here
function _setChildRunner(fn) { childRunnerOverride = fn; }
function defaultChildRunner(payload) {
  const r = spawnSync(process.execPath, [CHILD_PATH], {
    input: payload, ...CHILD_SPAWN_OPTS,
    encoding: 'utf8', maxBuffer: 8 * 1024 * 1024,
  });
  return { status: r.status, signal: r.signal || null, stdout: r.stdout || '', error: r.error || null };
}
// resolved = resolveIdPattern's success shape → { batch(texts) → {ids:(string|null)[]} | {failure} }
function makeIdMatcher(resolved) {
  if (resolved.origin !== 'config') {
    const re = new RegExp(resolved.source);
    return { batch: (texts) => ({ ids: texts.map((t) => leadId(t, re)) }) };
  }
  return { batch: (texts) => {
    const runner = childRunnerOverride || defaultChildRunner;
    let r;
    try { r = runner(JSON.stringify({ pattern: resolved.source, texts })); }
    catch (e) { return { failure: `spawn-error: ${String(e.message || e)}` }; }
    // timeout FIRST: a real spawnSync timeout carries ETIMEDOUT and/or the kill signal —
    // classifying by r.error first would misreport the termination as a spawn error
    if ((r.error && r.error.code === 'ETIMEDOUT') || r.signal === 'SIGKILL')
      return { failure: 'timeout (budget exceeded, child terminated)' };
    if (r.error) return { failure: `spawn-error: ${String(r.error.message || r.error)}` };
    if (r.signal) return { failure: `signal ${r.signal}` };
    if (r.status !== 0) return { failure: `non-zero-exit (${r.status})` };
    let parsed;
    try { parsed = JSON.parse(r.stdout); } catch { return { failure: 'malformed-output (not JSON)' }; }
    // strict success shape: exactly one JSON document whose ONLY key is a well-formed ids array
    if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed) ||
        Object.keys(parsed).length !== 1 || !Array.isArray(parsed.ids) ||
        parsed.ids.length !== texts.length ||
        parsed.ids.some((x) => x !== null && typeof x !== 'string'))
      return { failure: 'malformed-output (bad shape)' };
    return { ids: parsed.ids };
  } };
}
// the one sanitized failure text every consumer surfaces for a config-origin matcher failure
function matcherFailureMsg(failure) {
  return sanitizeMsg(`process-config id-pattern matching failed (${failure})`);
}
const inlineMatcher = (idRe) => makeIdMatcher({ source: idRe.source, origin: 'default' });

function mdFiles(target) {
  if (!fs.existsSync(target)) return [];
  const st = fs.statSync(target);
  if (st.isFile()) return [target];
  const out = [];
  for (const e of fs.readdirSync(target, { withFileTypes: true })) {
    const p = path.join(target, e.name);
    if (e.isDirectory()) out.push(...mdFiles(p));
    else if (e.name.endsWith('.md')) out.push(p);
  }
  return out.sort();
}

// Shared scenario scan over one text — STRUCTURE ONLY (no ID extraction; that is the
// matcher's job so config-origin patterns stay inside the terminable channel).
// Fenced content is documentation; scenarios inside DEPRECATED requirement blocks
// (the marker REMOVED injects) are excluded in every form — they are neither demanded
// nor listed, and their lingering tests become ORPHAN.
function scanTitles(text, label, pairs) {
  const clean = am.stripDeprecatedBlocks(stripFences(text));
  let m;
  SCENARIO_RE.lastIndex = 0;
  while ((m = SCENARIO_RE.exec(clean)) !== null) pairs.push([label, m[1]]);
}

// Batch-bind (label,title) pairs through a matcher → acc, or {failure} when the matcher fails.
function bindPairs(pairs, matcher) {
  const res = matcher.batch(pairs.map(([, title]) => title));
  if (res.failure) return { failure: res.failure };
  const acc = { byId: new Map(), idFiles: new Map(), unidentified: [] };
  pairs.forEach(([label, title], i) => {
    const id = res.ids[i];
    if (id) {
      if (!acc.byId.has(id)) { acc.byId.set(id, []); acc.idFiles.set(id, []); }
      acc.byId.get(id).push(title);
      acc.idFiles.get(id).push(label);
    } else acc.unidentified.push([label, title]);
  });
  return acc;
}

function dupsOf(acc) {
  return [...acc.byId.entries()].filter(([, titles]) => titles.length > 1)
    .map(([id]) => ({ id, files: [...new Set(acc.idFiles.get(id))] }));
}

// Collect scenarios from spec files.
// → { byId, unidentified:[[file,title]], files, missingTargets:[], duplicates:[{id,files}] }
// (+ failure when the matcher's channel fails — callers fail closed on it)
function collectScenarios(specTargets, idRe, matcher) {
  const m = matcher || inlineMatcher(idRe);
  const missingTargets = specTargets.filter((t) => !fs.existsSync(t));
  const files = [...new Set(specTargets.flatMap(mdFiles))].sort();
  const pairs = [];
  for (const f of files) scanTitles(fs.readFileSync(f, 'utf8'), f, pairs);
  const acc = bindPairs(pairs, m);
  if (acc.failure) return { failure: acc.failure, byId: new Map(), unidentified: [], files, missingTargets, duplicates: [] };
  return { byId: acc.byId, unidentified: acc.unidentified, files, missingTargets, duplicates: dupsOf(acc) };
}

// Same collection over in-memory texts (the projection path) — label = store-relative suffix.
function collectScenariosFromTexts(texts, idRe, matcher) {
  const m = matcher || inlineMatcher(idRe);
  const pairs = [];
  for (const [label, text] of texts) scanTitles(text, label, pairs);
  const acc = bindPairs(pairs, m);
  if (acc.failure) return { failure: acc.failure, byId: new Map(), unidentified: [], files: [...texts.keys()], missingTargets: [], duplicates: [] };
  return { byId: acc.byId, unidentified: acc.unidentified, files: [...texts.keys()], missingTargets: [], duplicates: dupsOf(acc) };
}

// ---- TAP lexer (tap-contract): TAP is a version-aware protocol, not a pile of regexes ----
const PLAN_LINE_RE = /^1\.\.(\d+)\s*(?:#.*)?$/;
const POINT_LINE_RE = /^(?:ok|not ok)(?:\s|$)/;
const POINT_NUM_RE = /^(?:ok|not ok)\s+(\d+)(?:\s|$)/;   // complete numeric token only — `ok 1abc` stays unnumbered
const SUPPORTED_TAP_VERSIONS = new Set([12, 13, 14]);

// split at the first UNESCAPED '#' (backslash escapes the next char); decode \\ and \# in the
// description ONLY (other backslash pairs stay literal) — so \# is never a directive delimiter
function splitDirective(rest) {
  let desc = '', directive = null;
  for (let i = 0; i < rest.length; i++) {
    const c = rest[i];
    if (c === '\\' && i + 1 < rest.length) { desc += c + rest[i + 1]; i++; continue; }
    if (c === '#') { directive = rest.slice(i + 1); break; }
    desc += c;
  }
  const isSkipTodo = directive !== null && /^\s*(skip|todo)/i.test(directive);
  const decoded = desc.replace(/\\([\\#])/g, '$1').trim();
  return { desc: decoded, isSkipTodo };
}

// does a text carry TAP-shaped tokens? (misrouted-channel detection — bail-out included)
function looksLikeTap(text) {
  return /^(?:TAP version |(?:not )?ok\b|1\.\.\d)/m.test(text || '') || /^\s*bail out!/im.test(text || '');
}

// Lex normalized stdout into typed top-level tokens. Line endings normalize first
// (CRLF and lone-CR both end a line — a failure never hides behind a line-ending style).
function lexTap(stdout) {
  const lines = stdout.replace(/\r\n/g, '\n').replace(/\r/g, '\n').split('\n');
  const tokens = [], problems = [];
  let yamlOpen = -1;
  for (let idx = 0; idx < lines.length; idx++) {
    const line = lines[idx], n = idx + 1;
    if (yamlOpen >= 0) {                                   // inside a top-level YAML block: opaque
      if (line === '...') yamlOpen = -1;
      continue;
    }
    if (/^\s*bail out!/i.test(line) && line.trim()) {      // case-insensitive, indentation-blind
      tokens.push({ kind: 'bailout', line: line.trim(), n }); continue;
    }
    if (/^\s/.test(line)) continue;                        // indented = nested subtest detail
    if (line === '---') { yamlOpen = n; continue; }
    if (line.startsWith('TAP version ')) {
      const m = /^TAP version (\d+)$/.exec(line);
      tokens.push({ kind: 'version', num: m ? Number(m[1]) : null, raw: line, n }); continue;
    }
    let m;
    if ((m = PLAN_LINE_RE.exec(line))) { tokens.push({ kind: 'plan', total: Number(m[1]), n }); continue; }
    if (/^pragma [+-]\w+$/.test(line)) continue;           // the ONLY ignored TAP-14 construct
    if (POINT_LINE_RE.test(line)) {
      const fail = line.startsWith('not ok');
      const nm = POINT_NUM_RE.exec(line);
      let rest = line.slice(fail ? 'not ok'.length : 'ok'.length);
      if (nm) rest = rest.replace(/^\s+\d+/, '');
      rest = rest.replace(/^\s+/, '');
      const { desc, isSkipTodo } = splitDirective(rest);
      const description = desc.replace(/^-\s+/, '');       // the dash separator is optional (TAP)
      tokens.push({ kind: 'point', fail, num: nm ? Number(nm[1]) : null, description, isSkipTodo, line, n });
      continue;
    }
    // anything else at column 0 is diagnostics (comments, prose) — including `ok:`-style prefixes
  }
  if (yamlOpen >= 0) problems.push(`unterminated YAML diagnostic block opened at line ${yamlOpen} — a stray --- must not swallow the rest of the stream`);
  return { tokens, problems };
}

// Parse TAP stdout → { results, untagged, untaggedFails, unattributedFailures, bailout,
//                      plans, points, dupNumbers, tapProblems }
// (+ matchFailure when the matcher's channel fails — callers fail closed on it)
// A # SKIP / # TODO directive is neither pass nor fail — a skipped test proves nothing.
function parseTap(out, idRe, matcher) {
  const results = new Map();
  const untagged = [];
  const unattributedFailures = [];
  const { tokens, problems } = lexTap(out);
  const tapProblems = [...problems];

  // version discipline: at most one, leading, exact digits, inside the closed matrix
  const versions = tokens.filter((t) => t.kind === 'version');
  const firstBody = tokens.find((t) => t.kind !== 'version');
  if (versions.length > 1) tapProblems.push('multiple TAP version lines — one version promise per stream');
  for (const v of versions) {
    if (v.num === null) { tapProblems.push(`unparsable TAP version line at line ${v.n}: ${v.raw}`); continue; }
    if (!SUPPORTED_TAP_VERSIONS.has(v.num)) tapProblems.push(`TAP version ${v.num} is not supported (supported: 12, 13, 14, or no version line)`);
    if (firstBody && v.n > firstBody.n) tapProblems.push(`TAP version line at line ${v.n} arrives after the stream began — the version must lead`);
  }

  const bail = tokens.find((t) => t.kind === 'bailout');
  const bailout = bail ? bail.line : null;

  const pts = tokens.filter((t) => t.kind === 'point');
  const plans = tokens.filter((t) => t.kind === 'plan');
  if (plans.length === 1) {
    const plan = plans[0];
    if (pts.some((p) => p.n < plan.n) && pts.some((p) => p.n > plan.n))
      tapProblems.push(`TAP plan at line ${plan.n} sits mid-stream (points before and after) — a plan promises the whole stream`);
    for (const p of pts) if (p.num !== null && (p.num < 1 || p.num > plan.total))
      tapProblems.push(`test point number ${p.num} is outside the plan range 1..${plan.total}`);
  }
  const numSeen = new Set(), dupSet = new Set();
  for (const p of pts) if (p.num !== null) { if (numSeen.has(p.num)) dupSet.add(p.num); else numSeen.add(p.num); }
  const dupNumbers = [...dupSet].sort((a, b) => a - b);

  const m = matcher || inlineMatcher(idRe);
  const batch = m.batch(pts.map((p) => p.description));
  if (batch.failure) {
    return { results, untagged, untaggedFails: 0, unattributedFailures, bailout,
      plans: plans.map((p) => p.total), points: pts.length, dupNumbers, tapProblems,
      matchFailure: batch.failure };
  }
  pts.forEach((p, i) => {
    const id = batch.ids[i];
    if (id !== null) {
      const cur = results.get(id) || { pass: 0, fail: 0, skip: 0 };
      if (p.isSkipTodo) cur.skip++;
      else cur[p.fail ? 'fail' : 'pass']++;
      results.set(id, cur);
    } else if (p.fail && !p.isSkipTodo) {
      unattributedFailures.push(p.line);
    } else {
      untagged.push(p.description);
    }
  });
  const untaggedFails = unattributedFailures.length;        // kept exported and compatible — doctor consumes it
  return { results, untagged, untaggedFails, unattributedFailures, bailout,
    plans: plans.map((p) => p.total), points: pts.length, dupNumbers, tapProblems };
}

// true when the test command produced output but not a single TAP result line was parsed —
// almost always means the runner used a human reporter (node: add --test-reporter=tap)
function zeroTapParsed(out, results, untagged, unattributedFailures = []) {
  if (results.size > 0 || untagged.length > 0 || unattributedFailures.length > 0) return false;
  if (!out.trim()) return false;
  // a TAP version line or plan (1..N) proves the reporter IS TAP — an empty suite is not a reporter problem
  if (/^TAP version \d+|^1\.\.\d+/m.test(out)) return false;
  return true;
}

function checkFlowState(state, name) {
  for (const key of ['change', 'tier', 'track', 'lineage', 'current-step']) {
    const v = state[key];
    if (v === undefined || v === '') return { id: 'C3', status: 'blocked', detail: `flow-state: required key '${key}' missing` };
    if (v.includes('<') || v.includes('>')) return { id: 'C3', status: 'blocked', detail: `flow-state: '${key}' is an unfilled placeholder (${v})` };
  }
  if (state.change !== name) return { id: 'C3', status: 'blocked', detail: `flow-state: 'change' is '${state.change}', expected '${name}'` };
  if (!STEP_ENUM.includes(state['current-step'])) return { id: 'C3', status: 'blocked', detail: `flow-state: 'current-step' '${state['current-step']}' not in the legal vocabulary` };
  if (!TIER_ENUM.includes(state.tier)) return { id: 'C3', status: 'blocked', detail: `flow-state: 'tier' '${state.tier}' not in {trivial, medium, large}` };
  return { id: 'C3', status: 'pass', detail: `legal (tier ${state.tier}, ${state['current-step']})` };
}

// the ledger vocabulary, one classifier shared by C4 and the corpus test (GT-15).
// leading token, case-insensitive; rejected-verified BEFORE rejected (alternation order).
const STATUS_RE = /^(open|fixed|verified|rejected-verified|rejected|advisory-acked|waived)\b/i;
function classifyStatus(status) {
  const m = STATUS_RE.exec(status);
  if (!m) return { legal: false, terminal: false, needsReason: false, hasReason: false, isWaived: false };
  const tok = m[1].toLowerCase();
  const needsReason = tok === 'rejected' || tok === 'rejected-verified' || tok === 'waived';
  return {
    legal: true,
    terminal: tok === 'verified' || tok === 'rejected-verified' || tok === 'waived' || tok === 'advisory-acked',
    needsReason,
    hasReason: !needsReason || /\w/.test(status.slice(m[0].length)),
    isWaived: tok === 'waived',
    token: tok,
  };
}

function gatesEntries(flowText) {

  const end = rest.search(/^[A-Za-z][\w-]*:/m);
  const block = end < 0 ? rest : rest.slice(0, end);
  const entries = [];
  for (const line of block.split('\n')) {
    if (/^\s*-\s/.test(line)) entries.push(line.trim());
    else if (entries.length && line.trim()) entries[entries.length - 1] += ' ' + line.trim();
  }
  return entries;
}

// a waive is a HUMAN act: one single gates: entry must carry the row ID as an exact
// token (LS-1 never matches inside LS-10) AND the word waive/waived.
function waiveEvidence(flowText, id) {
  const idRe = new RegExp(`(^|[^A-Za-z0-9-])${escapeRe(id)}([^A-Za-z0-9-]|$)`);
  return gatesEntries(flowText).some((e) => idRe.test(e) && /waiv/i.test(e));
}

function checkLedger(tier, stage, dir) {
  const p = path.join(dir, 'review', 'issues.md');
  if (!fs.existsSync(p)) {
    return tier === 'trivial'
      ? { id: 'C4', status: 'n/a', detail: 'no ledger — trivial tier may never open one' }
      : { id: 'C4', status: 'blocked', detail: `ledger missing at ${p}` };
  }
  const rows = parseLedger(fs.readFileSync(p, 'utf8'));
  const fsPath = dir ? path.join(dir, 'flow-state.md') : null;
  const flowText = fsPath && fs.existsSync(fsPath) ? fs.readFileSync(fsPath, 'utf8') : '';
  const bad = [];
  for (const r of rows) {
    const c = classifyStatus(r.status);
    if (!c.legal) { bad.push(`${r.id}: '${r.status}' is not in the ledger vocabulary`); continue; }
    if (c.needsReason && !c.hasReason) { bad.push(`${r.id} is ${c.token} without a reason`); continue; }
    if (c.isWaived && !waiveEvidence(flowText, r.id)) {
      bad.push(`${r.id} is waived without a gates: entry recording the human decision`); continue;
    }
    if (c.token === 'open') { bad.push(`${r.id} is open`); continue; }
    if (stage === 'archived' && !c.terminal) {
      bad.push(c.token === 'fixed'
        ? `${r.id} is fixed but never verified — reviewer must verify, or the human waives it`
        : `${r.id} is rejected without reviewer concurrence — flip to rejected-verified, or the human waives it`);
    }
  }
  return bad.length
    ? { id: 'C4', status: 'blocked', detail: bad.join('; ') }
    : { id: 'C4', status: 'pass', detail: `${rows.length} row(s), none blocking` };
}

// the bundle review/ dir is the shared evidence root for C4 and C5 — when present it must be
// a REAL contained directory (symlinked/escaping/non-dir entries block, never read through)
function reviewDirDefect(dir) {
  const rd = path.join(dir, 'review');
  let st;
  try { st = fs.lstatSync(rd); } catch { return null; }  // lstat, not exists: a dangling symlink is a defect, not absence
  if (st.isSymbolicLink()) return `review is a symlink: ${rd}`;
  if (!st.isDirectory()) return `review is not a directory: ${rd}`;
  if (!containsReal(dir, rd)) return `review escapes the change dir: ${rd}`;
  return null;
}

function checkEvidence(dir) {
  const rd = path.join(dir, 'review');
  const docs = [];
  if (fs.existsSync(rd)) {
    for (const e of fs.readdirSync(rd, { withFileTypes: true })) {
      if (!e.name.endsWith('.md') || e.name === 'issues.md' || /-raw(\.|$)/.test(e.name.replace(/\.md$/, ''))) continue;
      if (e.name.includes('-raw')) continue;
      const p = path.join(rd, e.name);
      if (fs.lstatSync(p).isSymbolicLink())
        return { id: 'C5', status: 'blocked', detail: `evidence doc is a symlink: ${e.name}` };
      if (!fs.lstatSync(p).isFile()) continue;
      docs.push(p);
    }
  }
  const missing = [];
  let verdictDocs = 0;
  for (const doc of docs) {
    if (!/^VERDICT:/m.test(fs.readFileSync(doc, 'utf8'))) continue;
    verdictDocs++;
    const stem = path.basename(doc).replace(/\.md$/, '');
    const hasRaw = fs.existsSync(rd) && fs.readdirSync(rd).some((n) => {
      if (!n.startsWith(stem + '-raw')) return false;
      const rp = path.join(rd, n);
      return fs.lstatSync(rp).isFile();
    });
    if (!hasRaw) missing.push(path.basename(doc));
  }
  if (missing.length) return { id: 'C5', status: 'blocked', detail: `verdict doc(s) without a raw archive: ${missing.join(', ')}` };
  return { id: 'C5', status: 'pass', detail: `${verdictDocs} review doc(s), every verdict has raw evidence` };
}

function checkKb(cwd, dir) {
  const specsDir = path.join(dir, 'specs');
  const modules = new Set();
  const walk = (d, base) => {
    if (!fs.existsSync(d)) return;
    for (const e of fs.readdirSync(d, { withFileTypes: true })) {
      const p = path.join(d, e.name);
      if (e.isDirectory()) walk(p, base);
      else if (e.name.endsWith('.md')) modules.add(path.relative(base, p).split(path.sep)[0]);
    }
  };
  walk(specsDir, specsDir);
  if (!modules.size) return { id: 'C6', status: 'n/a', detail: 'no delta specs to map' };

  // build the module → truth index (c6-truth-binding): a truth doc binds by its
  // declared store-module (default = basename), never by a filename assumption
  const truthDir = path.join(cwd, 'apriori', 'truth');
  const index = new Map();                 // module → { text, sourceFiles, basename }
  const conflicts = new Map();             // module → "declared by A and B"
  if (fs.existsSync(truthDir)) {
    for (const e of fs.readdirSync(truthDir).sort()) {
      if (!e.endsWith('.md')) continue;
      const text = fs.readFileSync(path.join(truthDir, e), 'utf8');
      const h2 = text.search(/^##\s/m);
      const header = h2 >= 0 ? text.slice(0, h2) : text;
      const smM = header.match(/^store-module:\s*(.+)$/m);
      const sfM = header.match(/^source-files:\s*(.+)$/m);
      const mods = smM ? smM[1].trim().split(/\s+/) : [e.replace(/\.md$/, '')];
      const sourceFiles = sfM ? sfM[1].trim().split(/\s+/) : null;   // null = default lib/<module>.js
      for (const m of mods) {
        if (index.has(m)) conflicts.set(m, `${m}: declared by both ${index.get(m).basename} and ${e}`);
        else index.set(m, { text, sourceFiles, basename: e });
      }
    }
  }
  const stripFencesKb = (t) => t.replace(/```[\s\S]*?```/g, '');
  const blocked = [], notes = [];
  let checked = 0;
  for (const m of [...modules].sort()) {
    if (conflicts.has(m)) { blocked.push(conflicts.get(m)); continue; }
    const entry = index.get(m);
    if (!entry) { notes.push(`${m}: no truth doc`); continue; }
    const noFence = stripFencesKb(entry.text);
    const sc = noFence.match(/^source-commit:\s+(\S+)/m);
    if (!sc) {
      const attempt = noFence.split('\n').some((l) => l.includes('source-commit:') && !/^source-commit:\s+\S+/.test(l));
      notes.push(attempt
        ? `${m}: source-commit is not in the canonical fence-outside line-start form 'source-commit: <ref>'`
        : `${m}: truth doc has no source-commit`);
      continue;
    }
    const ref = sc[1];
    const explicit = entry.sourceFiles !== null;
    const declared = explicit ? entry.sourceFiles : [`lib/${m}.js`];
    // an explicit declaration is a complete promise: every token must be verifiable
    const usable = [];
    let tokenBad = null;
    for (const rel of declared) {
      // an explicit token is a repo-relative promise: reject absolute/backslash/empty/. or .. segments
      if (explicit && (rel === '' || path.isAbsolute(rel) || rel.includes('\\') ||
          rel.split('/').some((seg) => seg === '' || seg === '.' || seg === '..'))) {
        tokenBad = `${m}: malformed source-files token (must be a normalized repo-relative path): ${rel}`; break;
      }
      const abs = path.join(cwd, rel);
      let st = null; try { st = fs.lstatSync(abs); } catch { /* absent */ }
      if (!st) { if (explicit) { tokenBad = `${m}: declared source-files token missing: ${rel}`; break; } continue; }
      if (st.isSymbolicLink()) { if (explicit) { tokenBad = `${m}: declared source-files token is a symlink: ${rel}`; break; } continue; }
      if (!containsReal(cwd, abs)) { if (explicit) { tokenBad = `${m}: declared source-files token escapes the repo: ${rel}`; break; } continue; }
      if (!st.isFile() && !st.isDirectory()) { if (explicit) { tokenBad = `${m}: declared source-files token is neither file nor directory: ${rel}`; break; } continue; }
      usable.push(rel);
    }
    if (tokenBad) { blocked.push(tokenBad); continue; }
    if (!usable.length) { notes.push(`${m}: no ${declared.join(' / ')} to compare`); continue; }
    const g = spawnSync('git', ['-C', cwd, 'log', '--oneline', `${ref}..HEAD`, '--', ...usable], { encoding: 'utf8' });
    if (g.error) { notes.push(`${m}: git unavailable (${g.error.message})`); continue; }
    if (g.status !== 0) { notes.push(`${m}: git failed (${(g.stderr || '').split('\n')[0]})`); continue; }
    const n = g.stdout.trim() ? g.stdout.trim().split('\n').length : 0;
    if (n > 0) blocked.push(`${m}: ${n} commit(s) since ${ref}`);
    else checked++;
  }
  if (blocked.length) return { id: 'C6', status: 'blocked', detail: blocked.join('; ') };
  if (checked > 0) return { id: 'C6', status: 'pass', detail: `${checked} module stamp(s) up to date${notes.length ? `; ${notes.join('; ')}` : ''}` };
  return { id: 'C6', status: 'n/a', detail: notes.join('; ') };
}

function checkBinding(cwd, name, stage, testCmd, idPattern) {
  const run = stage === 'in-flight'
    ? verify({ change: name, cwd, testCmd, idPattern })
    : verify({ specs: [path.join(cwd, 'apriori', 'specs')], cwd, testCmd, idPattern });
  if (run.errors.length) return { infra: run.errors };
  const v = run.verdict;
  const clean = v.clean && run.duplicates.length === 0;
  if (clean) return { check: { id: 'C1', status: 'pass', detail: `verify GREEN (${stage})` }, projection: run.projection };
  const parts = [];
  for (const [label, arr] of [['red', v.boundRed], ['unbound', v.unbound], ['orphan', v.orphan], ['unidentified', v.unidentified], ['unattributed-failures', v.unattributed || []], ['duplicate-IDs', run.duplicates]])
    if (arr.length) parts.push(`${arr.length} ${label}`);
  return { check: { id: 'C1', status: 'blocked', detail: `verify GAPS: ${parts.join(', ')}` }, projection: run.projection };
}


// C7: unstamped mutation deltas are denied by default — a waiver is always visible (GT-16).
// Archived stage: the deltas are already merged; there is nothing left to stamp-check.
function checkCas(projection, stage, noCas, cwd) {
  if (stage === 'archived') return { id: 'C7', status: 'n/a', detail: 'deltas already merged' };
  const um = (projection && projection.unstampedMutations) || [];
  if (!um.length) return { id: 'C7', status: 'pass', detail: 'every mutation delta is stamped' };  // nothing to consult — silent pass (GT-16)
  if (noCas) return { id: 'C7', status: 'pass', detail: 'waived (--no-cas)' };
  const problem = configCasProblem(cwd);                       // consumption-time only
  if (problem) return { id: 'C7', status: 'blocked', detail: `${problem} — a broken config never equals a waiver` };
  if (configCas(cwd) === 'optional') return { id: 'C7', status: 'pass', detail: 'waived (process-config cas: optional)' };
  return { id: 'C7', status: 'blocked',
    detail: `unstamped mutation delta(s): ${um.join(', ')} — run: apriori stamp <store-file> (or waive with --no-cas / a process-config cas: optional row)` };
}

   161	const SUPPORTED_TAP_VERSIONS = new Set([12, 13, 14]);

   163	// split at the first UNESCAPED '#' (backslash escapes the next char); decode \\ and \# in the
   164	// description ONLY (other backslash pairs stay literal) — so \# is never a directive delimiter
   165	function splitDirective(rest) {
   166	  let desc = '', directive = null;
   167	  for (let i = 0; i < rest.length; i++) {
   168	    const c = rest[i];
   169	    if (c === '\\' && i + 1 < rest.length) { desc += c + rest[i + 1]; i++; continue; }
   170	    if (c === '#') { directive = rest.slice(i + 1); break; }
   171	    desc += c;
   172	  }
   173	  const isSkipTodo = directive !== null && /^\s*(skip|todo)/i.test(directive);
   174	  const decoded = desc.replace(/\\([\\#])/g, '$1').trim();
   175	  return { desc: decoded, isSkipTodo };
   176	}

   178	// does a text carry TAP-shaped tokens? (misrouted-channel detection — bail-out included)
   179	function looksLikeTap(text) {
   180	  return /^(?:TAP version |(?:not )?ok\b|1\.\.\d)/m.test(text || '') || /^\s*bail out!/im.test(text || '');
   181	}

   183	// Lex normalized stdout into typed top-level tokens. Line endings normalize first
   184	// (CRLF and lone-CR both end a line — a failure never hides behind a line-ending style).
   185	function lexTap(stdout) {
   186	  const lines = stdout.replace(/\r\n/g, '\n').replace(/\r/g, '\n').split('\n');
   187	  const tokens = [], problems = [];
   188	  let yamlOpen = -1;
   189	  for (let idx = 0; idx < lines.length; idx++) {
   190	    const line = lines[idx], n = idx + 1;
   191	    if (yamlOpen >= 0) {                                   // inside a top-level YAML block: opaque
   192	      if (line === '...') yamlOpen = -1;
   193	      continue;
   194	    }
   195	    if (/^\s*bail out!/i.test(line) && line.trim()) {      // case-insensitive, indentation-blind
   196	      tokens.push({ kind: 'bailout', line: line.trim(), n }); continue;
   197	    }
   198	    if (/^\s/.test(line)) continue;                        // indented = nested subtest detail
   199	    if (line === '---') { yamlOpen = n; continue; }
   200	    if (line.startsWith('TAP version ')) {
   201	      const m = /^TAP version (\d+)$/.exec(line);
   202	      tokens.push({ kind: 'version', num: m ? Number(m[1]) : null, raw: line, n }); continue;
   203	    }
   204	    let m;
   205	    if ((m = PLAN_LINE_RE.exec(line))) { tokens.push({ kind: 'plan', total: Number(m[1]), n }); continue; }
   206	    if (/^pragma [+-]\w+$/.test(line)) continue;           // the ONLY ignored TAP-14 construct
   207	    if (POINT_LINE_RE.test(line)) {
   208	      const fail = line.startsWith('not ok');
   209	      const nm = POINT_NUM_RE.exec(line);
   210	      let rest = line.slice(fail ? 'not ok'.length : 'ok'.length);
   211	      if (nm) rest = rest.replace(/^\s+\d+/, '');
   212	      rest = rest.replace(/^\s+/, '');
   213	      const { desc, isSkipTodo } = splitDirective(rest);
   214	      const description = desc.replace(/^-\s+/, '');       // the dash separator is optional (TAP)
   215	      tokens.push({ kind: 'point', fail, num: nm ? Number(nm[1]) : null, description, isSkipTodo, line, n });
   216	      continue;
   217	    }
   218	    // anything else at column 0 is diagnostics (comments, prose) — including `ok:`-style prefixes
   219	  }
   220	  if (yamlOpen >= 0) problems.push(`unterminated YAML diagnostic block opened at line ${yamlOpen} — a stray --- must not swallow the rest of the stream`);
   221	  return { tokens, problems };
   222	}

   224	// Parse TAP stdout → { results, untagged, untaggedFails, unattributedFailures, bailout,
   225	//                      plans, points, dupNumbers, tapProblems }
   226	// (+ matchFailure when the matcher's channel fails — callers fail closed on it)
   227	// A # SKIP / # TODO directive is neither pass nor fail — a skipped test proves nothing.
   228	function parseTap(out, idRe, matcher) {
   229	  const results = new Map();
   230	  const untagged = [];
   231	  const unattributedFailures = [];
   232	  const { tokens, problems } = lexTap(out);
   233	  const tapProblems = [...problems];
   234	
   235	  // version discipline: at most one, leading, exact digits, inside the closed matrix
   236	  const versions = tokens.filter((t) => t.kind === 'version');
   237	  const firstBody = tokens.find((t) => t.kind !== 'version');
   238	  if (versions.length > 1) tapProblems.push('multiple TAP version lines — one version promise per stream');
   239	  for (const v of versions) {
   240	    if (v.num === null) { tapProblems.push(`unparsable TAP version line at line ${v.n}: ${v.raw}`); continue; }
   241	    if (!SUPPORTED_TAP_VERSIONS.has(v.num)) tapProblems.push(`TAP version ${v.num} is not supported (supported: 12, 13, 14, or no version line)`);
   242	    if (firstBody && v.n > firstBody.n) tapProblems.push(`TAP version line at line ${v.n} arrives after the stream began — the version must lead`);
   243	  }
   244	
   245	  const bail = tokens.find((t) => t.kind === 'bailout');
   246	  const bailout = bail ? bail.line : null;
   247	
   248	  const pts = tokens.filter((t) => t.kind === 'point');
   249	  const plans = tokens.filter((t) => t.kind === 'plan');
   250	  if (plans.length === 1) {
   251	    const plan = plans[0];
   252	    if (pts.some((p) => p.n < plan.n) && pts.some((p) => p.n > plan.n))
   253	      tapProblems.push(`TAP plan at line ${plan.n} sits mid-stream (points before and after) — a plan promises the whole stream`);
   254	    for (const p of pts) if (p.num !== null && (p.num < 1 || p.num > plan.total))
   255	      tapProblems.push(`test point number ${p.num} is outside the plan range 1..${plan.total}`);
   256	  }
   257	  const numSeen = new Set(), dupSet = new Set();
   258	  for (const p of pts) if (p.num !== null) { if (numSeen.has(p.num)) dupSet.add(p.num); else numSeen.add(p.num); }
   259	  const dupNumbers = [...dupSet].sort((a, b) => a - b);
   260	
   261	  const m = matcher || inlineMatcher(idRe);
   262	  const batch = m.batch(pts.map((p) => p.description));
   263	  if (batch.failure) {
   264	    return { results, untagged, untaggedFails: 0, unattributedFailures, bailout,
   265	      plans: plans.map((p) => p.total), points: pts.length, dupNumbers, tapProblems,
   266	      matchFailure: batch.failure };
   267	  }
   268	  pts.forEach((p, i) => {
   269	    const id = batch.ids[i];
   270	    if (id !== null) {
   271	      const cur = results.get(id) || { pass: 0, fail: 0, skip: 0 };
   272	      if (p.isSkipTodo) cur.skip++;
   273	      else cur[p.fail ? 'fail' : 'pass']++;
   274	      results.set(id, cur);
   275	    } else if (p.fail && !p.isSkipTodo) {
   276	      unattributedFailures.push(p.line);
   277	    } else {
   278	      untagged.push(p.description);
   279	    }
   280	  });
   281	  const untaggedFails = unattributedFailures.length;        // kept exported and compatible — doctor consumes it
   282	  return { results, untagged, untaggedFails, unattributedFailures, bailout,
   283	    plans: plans.map((p) => p.total), points: pts.length, dupNumbers, tapProblems };
   284	}

   286	// true when the test command produced output but not a single TAP result line was parsed —
   287	// almost always means the runner used a human reporter (node: add --test-reporter=tap)
   288	function zeroTapParsed(out, results, untagged, unattributedFailures = []) {
   289	  if (results.size > 0 || untagged.length > 0 || unattributedFailures.length > 0) return false;
   290	  if (!out.trim()) return false;
   291	  // a TAP version line or plan (1..N) proves the reporter IS TAP — an empty suite is not a reporter problem
   292	  if (/^TAP version \d+|^1\.\.\d+/m.test(out)) return false;
   293	  return true;
   294	}

   296	function runTestCommand(cmd, cwd) {
   297	  const r = spawnSync(cmd, { shell: true, cwd, encoding: 'utf8' });
   298	  return {
   299	    out: r.stdout || '',            // TAP parses from stdout ONLY (tap-contract)
   300	    stderr: r.stderr || '',         // a separate diagnostics channel, reported verbatim
   301	    status: r.status,               // null when killed by signal
   302	    signal: r.signal || null,
   303	    error: r.error ? String(r.error.message || r.error) : null,
   304	  };
   305	}

   307	// Pure evaluation: cross-reference scenarios vs results → verdict object.
   308	// A scenario whose only results are skips is UNBOUND — skips prove nothing.
   309	function evaluate(byId, unidentified, results, unattributedFailures = []) {
   310	  const specIds = [...byId.keys()].sort();
   311	  const boundGreen = [], boundRed = [], unbound = [], orphan = [];
   312	  for (const id of specIds) {
   313	    const r = results.get(id);
   314	    if (!r || (r.pass === 0 && r.fail === 0)) unbound.push(id);
   315	    else if (r.fail === 0) boundGreen.push(id);
   316	    else boundRed.push(id);
   317	  }
   318	  for (const id of [...results.keys()].sort()) if (!byId.has(id)) orphan.push(id);
   319	  const unattributed = unattributedFailures;
   320	  const clean = !boundRed.length && !unbound.length && !orphan.length && !unidentified.length && !unattributed.length;
   321	  return { boundGreen, boundRed, unbound, orphan, unidentified, unattributed, clean };
   322	}

   324	// Fail-closed guard: reasons this run cannot be trusted regardless of the TAP picture.
   325	// Returns [] when the run is trustworthy.
   326	function infraErrors(run) {
   327	  const errs = [];
   328	  for (const t of run.missingTargets) errs.push(`spec target does not exist: ${t}`);
   329	  if (!run.missingTargets.length && run.fileCount === 0)
   330	    errs.push('no spec files found under the given targets — nothing to verify');
   331	  if (run.fileCount > 0 && run.scenarioCount === 0)
   332	    errs.push('spec files contain zero scenarios — nothing to verify');
   333	  if (run.exec.error) errs.push(`test command failed to spawn: ${run.exec.error}`);
   334	  if (run.exec.signal) errs.push(`test command was killed by signal ${run.exec.signal}`);
   335	  if (run.bailout) errs.push(`test run aborted: ${run.bailout}`);
   336	  for (const p of run.tapProblems || []) errs.push(`TAP protocol: ${p}`);
   337	  if (run.noTap)
   338	    errs.push('test command produced output but ZERO TAP results were parsed on stdout — the command is probably not emitting TAP (node test runner: add --test-reporter=tap; TAP on stderr: append 2>&1)');
   339	  // the TAP plan is a checked promise — defensive defaults keep legacy run shapes
   340	  // (direct callers of this exported helper) valid; only verify-created runs carry the fields
   341	  const plans = run.plans || [], points = run.points || 0, dupNumbers = run.dupNumbers || [];
   342	  if (plans.length > 1)
   343	    errs.push(`multiple TAP plans in one run (${plans.map((n) => `1..${n}`).join(', ')}) — cannot attribute test points to plans; run one TAP stream per verify (split the test command)`);
   344	  else if (plans.length === 1 && plans[0] !== points)
   345	    errs.push(`TAP plan declares ${plans[0]} test point(s) but ${points} were parsed — output truncated or garbled; refusing to trust this run`);
   346	  else if (plans.length === 1 && dupNumbers.length)
   347	    errs.push(`duplicate TAP test-point number(s): ${dupNumbers.join(', ')}`);
   348	  if (run.exec.status !== null && run.exec.status !== 0 && run.failCount === 0)
   349	    errs.push(`test command exited with status ${run.exec.status} but no parsed TAP failure explains it — the TAP picture is incomplete or truncated; refusing to trust this run`);
   350	  return errs;
   351	}

   353	function formatReport(v, results, fileCount, extras = {}) {
   354	  const lines = [];
   355	  const specCount = v.boundGreen.length + v.boundRed.length + v.unbound.length;
   356	  const tagged = [...results.values()].reduce((s, r) => s + r.pass + r.fail, 0);
   357	  const skipped = [...results.values()].reduce((s, r) => s + (r.skip || 0), 0);
   358	  lines.push(`specs: ${fileCount} file(s), ${specCount} identified scenario(s)`);
   359	  lines.push(`tests: ${tagged} tagged result(s)${skipped ? `, ${skipped} skipped (not counted)` : ''}\n`);
   360	  const groups = [['BOUND-GREEN', v.boundGreen], ['BOUND-RED', v.boundRed],
   361	                 ['UNBOUND (scenario, no test)', v.unbound], ['ORPHAN (test, no scenario)', v.orphan]];
   362	  for (const [label, items] of groups) {
   363	    if (!items.length) continue;
   364	    lines.push(`${label === 'BOUND-GREEN' ? '✓' : '✗'} ${label}: ${items.length}`);
   365	    for (const id of items) {
   366	      const r = results.get(id);
   367	      lines.push(`    ${id}${r ? `  ${r.pass}p/${r.fail}f${r.skip ? `/${r.skip}s` : ''}` : ''}`);
   368	    }
   369	  }
   370	  if (v.unattributed && v.unattributed.length) {
   371	    lines.push(`✗ UNATTRIBUTED FAILURES (not ok without a scenario ID): ${v.unattributed.length}`);
   372	    for (const raw of v.unattributed.slice(0, 20))
   373	      lines.push(`    ${raw.length > 120 ? raw.slice(0, 119) + '…' : raw}`);
   374	    if (v.unattributed.length > 20) lines.push(`    … and ${v.unattributed.length - 20} more`);
   375	  }
   376	  if (v.unidentified.length) {
   377	    lines.push(`✗ UNIDENTIFIED (scenario, no ID — unbindable): ${v.unidentified.length}`);
   378	    for (const [f, t] of v.unidentified) lines.push(`    ${path.basename(f)}: ${t.slice(0, 60)}`);
   379	  }
   380	  if (extras.duplicates && extras.duplicates.length) {
   381	    lines.push(`✗ DUPLICATE scenario IDs (ambiguous binding): ${extras.duplicates.length}`);
   382	    for (const d of extras.duplicates) lines.push(`    ${d.id}: ${d.files.map((f) => path.basename(f)).join(', ')}`);
   383	  }
   384	  if (extras.stderr && extras.stderr.trim()) {
   385	    const sl = extras.stderr.replace(/\r\n/g, '\n').replace(/\r/g, '\n').split('\n').filter((l) => l.length);
   386	    lines.push(`— STDERR DIAGNOSTICS (not TAP): ${sl.length} line(s)`);
   387	    for (const raw of sl.slice(0, 20)) lines.push(`    ${raw.length > 120 ? raw.slice(0, 119) + '…' : raw}`);
   388	    if (sl.length > 20) lines.push(`    … and ${sl.length - 20} more`);
   389	  }
   390	  const errs = extras.errors || [];
   391	  lines.push('\nRESULT: ' + (errs.length ? 'ERROR — run not trustworthy (see stderr)'
   392	    : (v.clean && !(extras.duplicates || []).length ? 'GREEN — spec is the test suite' : 'GAPS')));
   393	  return lines.join('\n');
   394	}

   396	// Projection inputs for `verify --change` (all failure classes → run.errors, exit 2).
   397	// Roots resolve against cwd exactly as `apriori status` resolves change dirs.
   398	function buildChangeProjection(change, cwd) {
   399	  const changesDir = path.resolve(cwd, 'apriori', 'changes');
   400	  const storeRoot = path.resolve(cwd, 'apriori', 'specs');
   401	  const projection = { change, modules: [], conflicts: [], unstampedMutations: [] };
   402	  const d = am.discoverDeltas(changesDir, change);
   403	  if (d.errors.length) return { projection, errors: d.errors, texts: null };
   404	  const p = am.buildProjection(storeRoot, d.files, change);
   405	  projection.modules = p.modules;
   406	  projection.conflicts = p.conflicts;
   407	  projection.unstampedMutations = p.unstampedMutations;      // WARN grade — cli prints, verdict untouched
   408	  projection.notes = p.notes;
   409	  const errors = [...p.validation, ...p.hygiene, ...p.casMismatches];
   410	  if (p.conflicts.length) errors.push(`projection has ${p.conflicts.length} merge conflict(s) — no trustworthy projection: ${p.conflicts.join('; ')}`);
   411	  return { projection, errors, texts: errors.length ? null : p.texts };
   412	}

   414	// an errors-only run shape shared by every pre-test early exit (failed projection,
   415	// invalid pattern, matcher-channel failure) — fail closed WITHOUT running any tests
   416	function errorsRun(errors, projection) {
   417	  const verdict = evaluate(new Map(), [], new Map(), []);
   418	  const run = { verdict, results: new Map(), fileCount: 0, failCount: 0, scenarioCount: 0,
   419	    missingTargets: [], duplicates: [], bailout: null, noTap: false, tapProblems: [], stderr: '',
   420	    exec: { status: null, signal: null, error: null }, errors };
   421	  if (projection) run.projection = projection;
   422	  return run;
   423	}

   435	// Full verify run. opts: { specs:[], change, testCmd, idPattern, cwd }
   436	function verify(opts) {
   437	  const cwd = opts.cwd || '.';
   438	  // pattern resolution FIRST — before any spec content is read or any test command spawned
   439	  const resolved = resolveIdPattern(cwd, opts.idPattern === undefined ? null : opts.idPattern);
   440	  if (resolved.error)
   441	    return errorsRun([resolved.error], opts.change ? enumerateProjection(opts.change, cwd) : null);
   442	  const idRe = new RegExp(resolved.source);
   443	  const matcher = makeIdMatcher(resolved);
   444	  let collected, projection = null;
   445	  if (opts.change) {
   446	    const b = buildChangeProjection(opts.change, cwd);
   447	    projection = b.projection;
   448	    if (!b.texts) return errorsRun(b.errors, projection);
   449	    collected = collectScenariosFromTexts(b.texts, idRe, matcher);
   450	  } else {
   451	    collected = collectScenarios(opts.specs, idRe, matcher);
   452	  }
   453	  if (collected.failure) return errorsRun([matcherFailureMsg(collected.failure)], projection);
   454	  const { byId, unidentified, files, missingTargets, duplicates } = collected;
   455	  const exec = runTestCommand(opts.testCmd, cwd);
   456	  const parsed = parseTap(exec.out, idRe, matcher);
   457	  if (parsed.matchFailure) {
   458	    const run = errorsRun([matcherFailureMsg(parsed.matchFailure)], projection);
   459	    run.exec = { status: exec.status, signal: exec.signal, error: exec.error };
   460	    run.stderr = exec.stderr || '';
   260	  const parts = [];
   261	  for (const [label, arr] of [['red', v.boundRed], ['unbound', v.unbound], ['orphan', v.orphan], ['unidentified', v.unidentified], ['unattributed-failures', v.unattributed || []], ['duplicate-IDs', run.duplicates]])
   262	    if (arr.length) parts.push(`${arr.length} ${label}`);
   263	  return { check: { id: 'C1', status: 'blocked', detail: `verify GAPS: ${parts.join(', ')}` }, projection: run.projection };
   264	}

   267	// C7: unstamped mutation deltas are denied by default — a waiver is always visible (GT-16).
   268	// Archived stage: the deltas are already merged; there is nothing left to stamp-check.
   269	function checkCas(projection, stage, noCas, cwd) {
   270	  if (stage === 'archived') return { id: 'C7', status: 'n/a', detail: 'deltas already merged' };
   271	  const um = (projection && projection.unstampedMutations) || [];
   272	  if (!um.length) return { id: 'C7', status: 'pass', detail: 'every mutation delta is stamped' };  // nothing to consult — silent pass (GT-16)
   273	  if (noCas) return { id: 'C7', status: 'pass', detail: 'waived (--no-cas)' };
   274	  const problem = configCasProblem(cwd);                       // consumption-time only
   275	  if (problem) return { id: 'C7', status: 'blocked', detail: `${problem} — a broken config never equals a waiver` };
   276	  if (configCas(cwd) === 'optional') return { id: 'C7', status: 'pass', detail: 'waived (process-config cas: optional)' };
   277	  return { id: 'C7', status: 'blocked',
   278	    detail: `unstamped mutation delta(s): ${um.join(', ')} — run: apriori stamp <store-file> (or waive with --no-cas / a process-config cas: optional row)` };
   279	}

   281	// The whole evaluation. → { code, stage, checks, result, blocked, errors }
   282	function runGate(opts) {
   283	  const cwd = opts.cwd || process.cwd();
   284	  const res = { code: 0, stage: null, checks: [], result: 'PASS', blocked: 0, errors: [], change: opts.change || null };
   285	  if (!opts.change) return err(res, USAGE);   // the ONE usage constant — every path lists the same flags
   286	  const nameCheck = require('./resolve').validateChangeName(opts.change);
   287	  if (!nameCheck.ok) return err(res, `invalid change name '${opts.change}' (${nameCheck.kind}) — bare kebab-case, not date-prefixed, not a reserved name`);
   288	  const loc = resolveChange(cwd, opts.change);
   289	  if (loc.error) return err(res, loc.error);
   290	  res.stage = loc.stage;
   291	  const flowPath = path.join(loc.dir, 'flow-state.md');
   292	  if (!fs.existsSync(flowPath)) return err(res, `no readable flow-state.md at ${flowPath} — tier-aware checks are impossible`);
   293	  let state;
   294	  try { state = parseFlowState(fs.readFileSync(flowPath, 'utf8')); }
   295	  catch (e) { return err(res, `flow-state unreadable: ${e.message}`); }
   296	  let testCmd = opts.testCmd;
   297	  if (!testCmd) {
   298	    const c = configTestCmd(cwd);
   299	    if (c && c.error) return err(res, `verify: ${c.error}`);
   300	    testCmd = c;
   301	  }
   302	  if (!testCmd) return err(res, 'no test command: pass --test-cmd or add a test-cmd row to apriori/process-config.md');
   303	
   304	  const b = checkBinding(cwd, opts.change, loc.stage, testCmd, opts.idPattern === undefined ? null : opts.idPattern);
   305	  if (b.infra) { for (const e of b.infra) res.errors.push(`verify: ${e}`); res.result = 'ERROR'; res.code = 2; return res; }
   306	  res.checks.push(b.check);
   307	  const tier = TIER_ENUM.includes(state.tier) ? state.tier : null;
   308	  res.checks.push(checkTasks(loc.dir, tier));
   309	  res.checks.push(checkFlowState(state, opts.change));
   310	  const rdDefect = reviewDirDefect(loc.dir);
   311	  if (rdDefect) {
   312	    res.checks.push({ id: 'C4', status: 'blocked', detail: rdDefect });
   313	    res.checks.push({ id: 'C5', status: 'blocked', detail: rdDefect });
   314	  } else {
   315	    res.checks.push(checkLedger(tier, loc.stage, loc.dir));
   316	    res.checks.push(checkEvidence(loc.dir));
   317	  }
   318	
   319	  res.checks.push(checkKb(cwd, loc.dir));

   338	    errs.push('test command produced output but ZERO TAP results were parsed on stdout — the command is probably not emitting TAP (node test runner: add --test-reporter=tap; TAP on stderr: append 2>&1)');
   339	  // the TAP plan is a checked promise — defensive defaults keep legacy run shapes
   340	  // (direct callers of this exported helper) valid; only verify-created runs carry the fields
   341	  const plans = run.plans || [], points = run.points || 0, dupNumbers = run.dupNumbers || [];
   342	  if (plans.length > 1)
   343	    errs.push(`multiple TAP plans in one run (${plans.map((n) => `1..${n}`).join(', ')}) — cannot attribute test points to plans; run one TAP stream per verify (split the test command)`);
   344	  else if (plans.length === 1 && plans[0] !== points)
   345	    errs.push(`TAP plan declares ${plans[0]} test point(s) but ${points} were parsed — output truncated or garbled; refusing to trust this run`);
   346	  else if (plans.length === 1 && dupNumbers.length)
   347	    errs.push(`duplicate TAP test-point number(s): ${dupNumbers.join(', ')}`);
   348	  if (run.exec.status !== null && run.exec.status !== 0 && run.failCount === 0)
   349	    errs.push(`test command exited with status ${run.exec.status} but no parsed TAP failure explains it — the TAP picture is incomplete or truncated; refusing to trust this run`);
   350	  return errs;
   351	}

   353	function formatReport(v, results, fileCount, extras = {}) {
   354	  const lines = [];
   355	  const specCount = v.boundGreen.length + v.boundRed.length + v.unbound.length;
   356	  const tagged = [...results.values()].reduce((s, r) => s + r.pass + r.fail, 0);
   357	  const skipped = [...results.values()].reduce((s, r) => s + (r.skip || 0), 0);
   358	  lines.push(`specs: ${fileCount} file(s), ${specCount} identified scenario(s)`);
   359	  lines.push(`tests: ${tagged} tagged result(s)${skipped ? `, ${skipped} skipped (not counted)` : ''}\n`);
   360	  const groups = [['BOUND-GREEN', v.boundGreen], ['BOUND-RED', v.boundRed],
   361	                 ['UNBOUND (scenario, no test)', v.unbound], ['ORPHAN (test, no scenario)', v.orphan]];
   362	  for (const [label, items] of groups) {
   363	    if (!items.length) continue;
   364	    lines.push(`${label === 'BOUND-GREEN' ? '✓' : '✗'} ${label}: ${items.length}`);
   365	    for (const id of items) {
   366	      const r = results.get(id);
   367	      lines.push(`    ${id}${r ? `  ${r.pass}p/${r.fail}f${r.skip ? `/${r.skip}s` : ''}` : ''}`);
   368	    }
   369	  }
   370	  if (v.unattributed && v.unattributed.length) {
   371	    lines.push(`✗ UNATTRIBUTED FAILURES (not ok without a scenario ID): ${v.unattributed.length}`);
   372	    for (const raw of v.unattributed.slice(0, 20))
   373	      lines.push(`    ${raw.length > 120 ? raw.slice(0, 119) + '…' : raw}`);
   374	    if (v.unattributed.length > 20) lines.push(`    … and ${v.unattributed.length - 20} more`);
   375	  }
   376	  if (v.unidentified.length) {
   377	    lines.push(`✗ UNIDENTIFIED (scenario, no ID — unbindable): ${v.unidentified.length}`);
   378	    for (const [f, t] of v.unidentified) lines.push(`    ${path.basename(f)}: ${t.slice(0, 60)}`);
   379	  }
   380	  if (extras.duplicates && extras.duplicates.length) {
   381	    lines.push(`✗ DUPLICATE scenario IDs (ambiguous binding): ${extras.duplicates.length}`);
   382	    for (const d of extras.duplicates) lines.push(`    ${d.id}: ${d.files.map((f) => path.basename(f)).join(', ')}`);
   383	  }
   384	  if (extras.stderr && extras.stderr.trim()) {
   385	    const sl = extras.stderr.replace(/\r\n/g, '\n').replace(/\r/g, '\n').split('\n').filter((l) => l.length);
   386	    lines.push(`— STDERR DIAGNOSTICS (not TAP): ${sl.length} line(s)`);
   387	    for (const raw of sl.slice(0, 20)) lines.push(`    ${raw.length > 120 ? raw.slice(0, 119) + '…' : raw}`);
   388	    if (sl.length > 20) lines.push(`    … and ${sl.length - 20} more`);
   389	  }
   390	  const errs = extras.errors || [];
   391	  lines.push('\nRESULT: ' + (errs.length ? 'ERROR — run not trustworthy (see stderr)'
   392	    : (v.clean && !(extras.duplicates || []).length ? 'GREEN — spec is the test suite' : 'GAPS')));
   393	  return lines.join('\n');
   394	}

   435	// Full verify run. opts: { specs:[], change, testCmd, idPattern, cwd }
   436	function verify(opts) {
   437	  const cwd = opts.cwd || '.';
   438	  // pattern resolution FIRST — before any spec content is read or any test command spawned
   439	  const resolved = resolveIdPattern(cwd, opts.idPattern === undefined ? null : opts.idPattern);
   440	  if (resolved.error)
   441	    return errorsRun([resolved.error], opts.change ? enumerateProjection(opts.change, cwd) : null);
   442	  const idRe = new RegExp(resolved.source);
   443	  const matcher = makeIdMatcher(resolved);
   444	  let collected, projection = null;
   445	  if (opts.change) {
   446	    const b = buildChangeProjection(opts.change, cwd);
   447	    projection = b.projection;
   448	    if (!b.texts) return errorsRun(b.errors, projection);
   449	    collected = collectScenariosFromTexts(b.texts, idRe, matcher);
   450	  } else {
   451	    collected = collectScenarios(opts.specs, idRe, matcher);
   452	  }
   453	  if (collected.failure) return errorsRun([matcherFailureMsg(collected.failure)], projection);
   454	  const { byId, unidentified, files, missingTargets, duplicates } = collected;
   455	  const exec = runTestCommand(opts.testCmd, cwd);
   456	  const parsed = parseTap(exec.out, idRe, matcher);
   457	  if (parsed.matchFailure) {
   458	    const run = errorsRun([matcherFailureMsg(parsed.matchFailure)], projection);
   459	    run.exec = { status: exec.status, signal: exec.signal, error: exec.error };
   460	    run.stderr = exec.stderr || '';
   461	    return run;
   462	  }
   463	  const { results, untagged, untaggedFails, unattributedFailures, bailout, plans, points, dupNumbers, tapProblems } = parsed;
   464	  const verdict = evaluate(byId, unidentified, results, unattributedFailures);
   465	  const failCount = [...results.values()].reduce((s, r) => s + r.fail, 0) + untaggedFails;
   466	  const run = {
   467	    verdict, results, fileCount: files.length, failCount,
   468	    scenarioCount: byId.size + unidentified.length,
   469	    missingTargets, duplicates, bailout, plans, points, dupNumbers,
   470	    noTap: zeroTapParsed(exec.out, results, untagged, unattributedFailures)
   471	      || (!exec.out.trim() && looksLikeTap(exec.stderr)),  // TAP went to stderr — same zero-TAP cure (2>&1)
   472	    tapProblems,
   473	    stderr: exec.stderr || '',
   474	    exec: { status: exec.status, signal: exec.signal, error: exec.error },
   475	  };
   476	  if (projection) run.projection = projection;
   477	  run.errors = infraErrors(run);
   478	  return run;
   479	}

   540	                       : formatReport(run.verdict, run.results, run.fileCount, { duplicates: run.duplicates, errors: run.errors, stderr: run.stderr }));
   541	    if (run.errors.length) return 2;
   542	    return run.verdict.clean && run.duplicates.length === 0 ? 0 : 1;
   543	  });

    45	function fingerprint(text) {
    46	  const norm = text.replace(/\r\n/g, '\n').replace(/\r/g, '\n');

    50	const STAMP_LINE_RE = /^<!--\s*apriori-base:\s*(\S+)\s*-->\s*$/gm;
    51	// any standalone comment line ATTEMPTING to be a stamp — a malformed attempt must be an error,
    52	// never silently treated as "unstamped" (that would quietly disable CAS)
    53	const STAMP_ATTEMPT_RE = /^\s*<!--(?=[^>]*apriori-base)[^>]*-->\s*$/gm;
    54	
    55	// → { stamp: 'sha256:<hex>' | 'new' | null, problems: [] }
    56	// Exactly one stamp line, before the first delta section, well-formed digest.
    57	function parseStamp(text) {
    58	  const problems = [];
    59	  const sectionIdx = text.search(SECTION_SPLIT_RE);
    60	  STAMP_ATTEMPT_RE.lastIndex = 0;
    61	  let m;
    62	  while ((m = STAMP_ATTEMPT_RE.exec(text)) !== null) {
    63	    STAMP_LINE_RE.lastIndex = 0;
    64	    if (!STAMP_LINE_RE.test(m[0].trim())) problems.push(`malformed apriori-base stamp line: ${m[0].trim()}`);
    65	  }
    66	  const found = [];
    67	  STAMP_LINE_RE.lastIndex = 0;
    68	  while ((m = STAMP_LINE_RE.exec(text)) !== null) found.push({ value: m[1], index: m.index });
    69	  if (!found.length) return { stamp: null, problems };
    70	  if (found.length > 1) problems.push('carries more than one apriori-base stamp line');
    71	  for (const f of found) {
    72	    if (sectionIdx >= 0 && f.index > sectionIdx) problems.push('apriori-base stamp appears after the first delta section heading');
    73	    if (f.value !== 'new' && !/^sha256:[0-9a-f]{64}$/.test(f.value)) problems.push(`malformed apriori-base stamp '${f.value}'`);
    74	  }
    75	  return { stamp: problems.length ? null : found[0].value, problems };
    76	}

    78	// ---- delta parsing ---------------------------------------------------------
    79	
    80	// per-line forms of the shared regexes (no /m — the walker feeds one normalized line at a time)
    81	const SECTION_LINE_RE = /^##\s+(ADDED|MODIFIED|REMOVED|RENAMED)\s+Requirements\s*$/;
    82	const H2_LINE_RE = /^##\s/;
    83	const REQ_LINE_RE = /^###\s+Requirement:\s+(.+?)\s*$/;
    84	const SCENARIO_LINE_RE = /^####\s+Scenario:/;
    85	const RENAME_LINE_RE = /^\s*-\s*(.+?)\s*->\s*(.+?)\s*$/;
    86	const STAMP_ATTEMPT_LINE_RE = /^\s*<!--(?=[^>]*apriori-base)[^>]*-->\s*$/;
    87	const STAMP_STRICT_LINE_RE = /^<!--\s*apriori-base:\s*(\S+)\s*-->\s*$/;
    88	const FENCE_LINE_RE = /^\s*```/;
    89	
    90	// strict form: a sequential, fully-consuming line walker — every line (outside
    91	// code fences, which are opaque) belongs to exactly one legal construct, and
    92	// anything else is a problems[] entry carrying its 1-based line number.
    93	// Well-formed deltas parse byte-identically to the old split()-based grammar.
    94	function parseDeltaStrict(text) {
    95	  const problems = [];
    96	  const buckets = { ADDED: new Map(), MODIFIED: new Map(), REMOVED: new Map(), RENAMED: [] };
    97	  const seen = new Map();               // name -> first section carrying it
    98	  const lines = text.split('\n').map((l) => (l.endsWith('\r') ? l.slice(0, -1) : l));
    99	
   100	  let state = 'FILE_PREAMBLE';          // | 'IN_SECTION' | 'IN_REQUIREMENT' | 'SKIP_UNRECOGNIZED'
   101	  let kind = null;                      // current section kind while IN_SECTION/IN_REQUIREMENT
   102	  let blockName = null, blockLines = null, blockDiscard = false;
   103	  let inFence = false;
   104	  let stamp = null, stampSeen = false, stampProblems = false, sectionSeen = false;
   105	
   106	  const flush = () => {
   107	    if (blockLines === null) return;
   108	    if (!blockDiscard) buckets[kind].set(blockName, blockLines.join('\n').replace(/\s+$/, '') + '\n');
   109	    blockName = null; blockLines = null; blockDiscard = false;
   110	  };
   111	  const stampProblem = (msg) => { problems.push(msg); stampProblems = true; };
   112	
   113	  for (let i = 0; i < lines.length; i++) {
   114	    const line = lines[i], n = i + 1;
   115	    if (inFence) {                      // opaque: never structure, never a problem
   116	      if (blockLines !== null) blockLines.push(line);
   117	      if (FENCE_LINE_RE.test(line)) inFence = false;
   118	      continue;
   119	    }
   120	    if (FENCE_LINE_RE.test(line)) {
   121	      inFence = true;
   122	      if (blockLines !== null) blockLines.push(line);
   123	      continue;
   124	    }
   125	    const sec = SECTION_LINE_RE.exec(line);
   126	    if (sec) { flush(); state = 'IN_SECTION'; kind = sec[1]; sectionSeen = true; continue; }
   127	    if (H2_LINE_RE.test(line)) {        // one problem per unrecognized heading; its lines are skipped, not re-homed
   128	      flush();
   129	      problems.push(`line ${n}: unrecognized section heading '${line.trim()}'`);
   130	      state = 'SKIP_UNRECOGNIZED'; kind = null;
   131	      continue;
   132	    }
   133	    if (state === 'SKIP_UNRECOGNIZED') continue;   // covered by the heading's problem — no flood, no attribution (stamps included)
   134	    // stamps are matched in every remaining state so a stray one is never absorbed as body text
   135	    if (STAMP_ATTEMPT_LINE_RE.test(line)) {
   136	      const m = STAMP_STRICT_LINE_RE.exec(line.trim());
   137	      if (!m) { stampProblem(`line ${n}: malformed apriori-base stamp line: ${line.trim()}`); continue; }
   138	      if (stampSeen) { stampProblem(`line ${n}: carries more than one apriori-base stamp line`); continue; }
   139	      stampSeen = true;
   140	      if (sectionSeen) { stampProblem(`line ${n}: apriori-base stamp appears after the first delta section heading`); continue; }
   141	      if (m[1] !== 'new' && !/^sha256:[0-9a-f]{64}$/.test(m[1])) { stampProblem(`line ${n}: malformed apriori-base stamp '${m[1]}'`); continue; }
   142	      stamp = m[1];
   143	      continue;
   144	    }
   145	    const req = REQ_LINE_RE.exec(line);
   146	    if (req) {
   147	      if (state === 'FILE_PREAMBLE') { problems.push(`line ${n}: requirement block before any section heading`); continue; }
   148	      if (kind === 'RENAMED') {
   149	        // the whole illegal block is discarded — its body must not be reinterpreted as rename lines
   150	        problems.push(`line ${n}: requirement block inside the RENAMED section`);
   151	        flush();
   152	        state = 'IN_REQUIREMENT'; blockName = null; blockLines = []; blockDiscard = true;
   153	        continue;
   154	      }
   155	      flush();
   156	      state = 'IN_REQUIREMENT';
   157	      blockName = req[1].trim(); blockLines = [line]; blockDiscard = false;
   158	      if (buckets[kind].has(blockName)) {          // first block wins, as before
   159	        problems.push(`line ${n}: duplicate requirement '${blockName}' in the ${kind} section`);

   209	// Pure merge. Returns { store: Map, merged, modified, deprecated, renamed, conflicts, unchanged }
   210	function merge(storeText, delta, change) {
   211	  const parsed = parseRequirementsStrict(storeText);
   212	  const store = parsed.map;
   213	  const merged = [], modified = [], deprecated = [], renamed = [], conflicts = [], unchanged = [];
   214	  // a corrupt store (same requirement name twice) must never be silently collapsed
   215	  for (const d of parsed.duplicates) conflicts.push(`duplicate requirement '${d}' in the store (corrupt store)`);
   216	  const renamedTargets = new Set();   // names created by THIS run's renames — an ADDED hitting one is a same-delta collision, never a rerun no-op
   217	  // RENAMED first: rename the store block's ID, preserving its content
   218	  for (const [oldName, newName] of (delta.RENAMED || [])) {
   219	    if (!store.has(oldName)) {
   220	      // rerun signature: source already gone AND target present → this rename already happened
   221	      if (store.has(newName)) { unchanged.push(`${oldName} -> ${newName} (already renamed)`); continue; }
   222	      conflicts.push(`RENAMED '${oldName}' has no target in store`); continue;
   223	    }
   224	    if (store.has(newName)) { conflicts.push(`RENAMED target '${newName}' already exists in store`); continue; }
   225	    const block = store.get(oldName);
   226	    const renamedBlock = block.replace(/^###\s+Requirement:\s+.+$/m, `### Requirement: ${newName}`);
   227	    // rebuild the map preserving order, swapping the key at the old position
   228	    const rebuilt = new Map();
   229	    for (const [k, v] of store) rebuilt.set(k === oldName ? newName : k, k === oldName ? renamedBlock : v);
   230	    store.clear();
   231	    for (const [k, v] of rebuilt) store.set(k, v);
   232	    renamed.push(`${oldName} -> ${newName}`);
   233	    renamedTargets.add(newName);
   234	  }
   235	  for (const [name, block] of delta.ADDED) {
   236	    if (store.has(name)) {
   237	      // idempotent rerun: identical content means this delta already merged — a no-op, not a collision.
   238	      // But a name just created by THIS run's RENAMED is a same-delta collision, never a rerun.
   239	      if (!renamedTargets.has(name) && store.get(name).trim() === block.trim()) unchanged.push(name);
   240	      else conflicts.push(`ADDED '${name}' already exists in store`);
   241	    } else { store.set(name, block); merged.push(name); }
   242	  }
   243	  for (const [name, block] of delta.MODIFIED) {
   244	    if (!store.has(name)) conflicts.push(`MODIFIED '${name}' has no target in store`);
   245	    // already applied (rerun signature) — same trim comparison the ADDED no-op uses
   246	    else if (store.get(name).trim() === block.trim()) unchanged.push(name);
   247	    else { store.set(name, block); modified.push(name); }
   248	  }
   249	  for (const name of delta.REMOVED.keys()) {
   250	    if (!store.has(name)) {
   251	      // rerun signature: already deprecated BY THIS CHANGE → no-op; by another change → real collision
   252	      const depByThis = `${name}  _deprecated (superseded by ${change})_`;
   253	      if (store.has(depByThis)) { unchanged.push(`${name} (already deprecated)`); continue; }
   254	      const depOther = [...store.keys()].find((k) => k.startsWith(`${name}  _deprecated (superseded by `));
   255	      if (depOther) { conflicts.push(`REMOVED '${name}' was already deprecated by a different change ('${depOther}')`); continue; }
   256	      conflicts.push(`REMOVED '${name}' has no target in store`);
   257	    } else {
   258	      const block = store.get(name);
   259	      const nl = block.indexOf('\n');
   260	      store.set(name, block.slice(0, nl) + `  _deprecated (superseded by ${change})_` + block.slice(nl));
   261	      deprecated.push(name);
   262	    }
   263	  }
   264	  return { store, merged, modified, deprecated, renamed, conflicts, unchanged };
   265	}

   275	// Realpath containment: target (followed through symlinks; not-yet-existing targets judged
   276	// by their nearest existing ancestor) must resolve STRICTLY inside root. Fail-closed.
   277	function containsReal(root, target) {
   278	  let realRoot;
   279	  try { realRoot = fs.realpathSync(root); } catch { return false; }
   280	  let cur = path.resolve(target);
   281	  const rest = [];
   282	  while (!fs.existsSync(cur)) {
   283	    const parent = path.dirname(cur);
   284	    if (parent === cur) return false;
   285	    rest.unshift(path.basename(cur));
   286	    cur = parent;
   287	  }
   288	  let realCur;
   289	  try { realCur = fs.realpathSync(cur); } catch { return false; }
   290	  const full = rest.length ? path.join(realCur, ...rest) : realCur;
   291	  return full !== realRoot && (full + path.sep).startsWith(realRoot + path.sep);
   292	}

   294	function mdFilesUnder(dir) {
   295	  const out = [];
   296	  const walk = (d) => {
   297	    for (const e of fs.readdirSync(d, { withFileTypes: true })) {
   298	      const p = path.join(d, e.name);
   299	      // Dirents reflect lstat: a symlink is neither file nor directory. Follow it explicitly —
   300	      // silently skipping a symlinked dir would hide deltas (fail-open); containment judges the target.
   301	      let isDir = e.isDirectory();
   302	      if (e.isSymbolicLink()) {
   303	        try { isDir = fs.statSync(p).isDirectory(); } catch { isDir = false; /* broken link: fall through, read fails loudly */ }
   304	      }
   305	      if (isDir) walk(p);
   306	      else if (e.name.endsWith('.md')) out.push(p);
   307	    }
   308	  };
   309	  if (fs.existsSync(dir)) walk(dir);
   310	  return out.sort();
   311	}

// cross-platform TAP emitter: node -e works identically under cmd.exe, PowerShell and sh
function tapCmd(...lines) {
  return `node -e "${lines.map((l) => `console.log('${l}')`).join(';')}"`;
}

// Build a project tree: { 'apriori/specs/kv/spec.md': '...', 'apriori/changes/c/specs/kv/spec.md': '...' }
function mkProject(files) {
  const root = fs.mkdtempSync(path.join(os.tmpdir(), 'apriori-proj-'));
  for (const [rel, content] of Object.entries(files)) {
    const p = path.join(root, rel);
    fs.mkdirSync(path.dirname(p), { recursive: true });
    fs.writeFileSync(p, content);
  }
  return root;
}

const STORE_KV = '### Requirement: Alpha\nbase req\n\n#### Scenario: XA-01 first\n- WHEN x\n- THEN y\n';

function jsonCli(args) {
  let out = '';
  const orig = console.log;
  console.log = (s) => { out += s + '\n'; };
  let code;
  try { code = cli(args); } finally { console.log = orig; }
  return { code, json: JSON.parse(out) };
}

function mkProject(files) {
  const root = fs.mkdtempSync(path.join(os.tmpdir(), 'apriori-gate-'));
  for (const [rel, content] of Object.entries(files)) {
    const p = path.join(root, rel);
    fs.mkdirSync(path.dirname(p), { recursive: true });
    fs.writeFileSync(p, content);
  }
  return root;
}

test('SR-34 bare and half-shaped not-ok points block even on exit 0', () => {
  const { file } = tmpSpec('#### Scenario: XX-01 a\n');
  for (const bad of ['not ok', 'not ok 2', 'not ok 2 teardown', 'not ok - teardown failed']) {

  assert.strictEqual(only.status, 1, only.stdout + only.stderr);
  assert.match(only.stdout, /UNATTRIBUTED FAILURES/);
  assert.doesNotMatch(only.stderr, /ZERO TAP results/);
});

test('SR-37 the reporting contract is exact', () => {
  const { file } = tmpSpec('#### Scenario: XX-01 a\n');
  const mk = [
    "console.log('ok 1 - XX-01 a')",
    "for(let i=0;i<25;i++)console.log('not ok '+(i+2)+' - fail'+(i===0?' '+'x'.repeat(150):' '+i))",
  ].join(';');
  const r = runCli(['--specs', file, '--test-cmd', `node -e "${mk}"`, '--json']);
  assert.strictEqual(r.status, 1, r.stdout + r.stderr);
  const j = JSON.parse(r.stdout);
  assert.strictEqual(j.unattributedFailures.count, 25);
  assert.strictEqual(j.unattributedFailures.lines.length, 25);
  assert.ok(j.unattributedFailures.lines[0].length > 120, 'JSON lines untruncated');
  // human report: first 20, 120-char cap incl. ellipsis, "and N more"
  const h = runCli(['--specs', file, '--test-cmd', `node -e "${mk}"`]);
  const seg = h.stdout.slice(h.stdout.indexOf('UNATTRIBUTED'));
  const listed = seg.split('\n').filter((l) => /fail/.test(l));
  assert.strictEqual(listed.length, 20, 'first 20 listed');
  const long = listed.find((l) => l.includes('x'.repeat(10)));
  assert.ok(long.trim().length <= 120 && long.trim().endsWith('…'), 'cut to 119 + ellipsis');
  assert.match(seg, /and 5 more/);
  // GREEN carries the stable empty shape
  const g = runCli(['--specs', file, '--test-cmd', `node -e "console.log('ok 1 - XX-01 a')"`, '--json']);
  const gj = JSON.parse(g.stdout);
  assert.deepStrictEqual(gj.unattributedFailures, { count: 0, lines: [] });
});

// write a raw TAP stream to a file and emit it verbatim via node (cross-platform, byte-exact)
function tapFile(content, toStderr = false) {
  const d = fs.mkdtempSync(path.join(os.tmpdir(), 'apriori-tap-'));
  const f = path.join(d, 'stream.txt');
  fs.writeFileSync(f, content);
  const target = toStderr ? 'process.stderr' : 'process.stdout';
  return `node -e "${target}.write(require('fs').readFileSync(process.argv[1],'utf8'))" ${JSON.stringify(f)}`;
}

- 辅助知识：`apriori/truth/spec-runner.md`、`apriori/truth/gate.md`

## 维度 1：target state B 是否清晰、无歧义

结论：不通过。存在 REQ-1、REQ-2、REQ-3、REQ-4。

### REQ-1：`RENAMED` 的目标语义与现有 delta 语法冲突

描述：

需求 B1 写“`RENAMED` 取改名后的 ID”，AC3 又要求“`RENAMED` 后按新 ID 要求”。但 state A 中 `RENAMED` 的语法是 `Old Requirement -> New Requirement`，重命名的是 Requirement 名称；`archive-merge.merge()` 保留整个块内容，场景 ID 不会变化。现有测试 SR-19 也明确断言 `RENAMED` 后 `XA-01` 保持不变。

风险：

AI 无法判断应该：

- 沿用现有语法，仅将改名后 Requirement 块中的原场景 ID 纳入 change scope；
- 自动改写场景 ID；
- 还是把场景 ID 改名视为另一个 `MODIFIED` 操作。

不同选择会产生不同的 change verdict，并可能破坏 archive/project 一致性。

建议修复：

明确规定：`RENAMED` 只重命名 Requirement；change scope 包含改名后目标 Requirement 块在 projection 中的场景，场景 ID 原样保留。将 AC3 的 oracle 改成类似：

> 如果 `Alpha -> Gamma`，且原块含 `XA-01`，则 projection 中 `Gamma` 的 `XA-01` 属于 change scope；不会凭空产生新场景 ID。场景 ID 的改变必须由 `MODIFIED` 块显式表达。

### REQ-2：change scope 使用“ID 集”定义，无法确定 duplicate 和 unidentified 的边界

描述：

B1 将 change scope 定义为场景 ID 集，但以下判定依赖“场景 occurrence 的来源”，不能只靠 ID 集完成：

- change 中的场景与未修改 store 场景使用同一个 ID；
- duplicate 的两个 occurrence 都在 change 中；
- duplicate 完全发生在 change 外；
- 未识别场景位于 `ADDED`、`MODIFIED`、`REMOVED` 或未修改 store 中；
- `ADDED`/`MODIFIED` 命中 state A 的 idempotent `unchanged` 路径。

“change 范围内无 duplicate”和“delta 内无 unidentified”也不是同一个边界：前者描述 projection，后者描述原始 delta。

风险：

实现可能先把 projection 压成 `Map<ID,...>`，丢失 provenance，随后无法可靠判断 duplicate/unidentified 是否应进入 change verdict。尤其是“一个 changed occurrence 与一个 unchanged occurrence 撞 ID”可能被不同实现判成 GREEN 或 GAPS。

建议修复：

把 change scope 定义为带 provenance 的 scenario occurrence 集，再派生 ID 集。补充操作真值表：

- `ADDED`：目标 Requirement 在 projection 中的全部 scenario occurrences；
- `MODIFIED`：替换后目标块中的全部 scenario occurrences，包括保留的旧 ID；
- `REMOVED`：不贡献 scenario occurrence；
- `RENAMED`：改名后目标块中的全部 occurrence，ID 不变；
- idempotent `unchanged`：是否仍贡献 scope，必须明确。

同时明确：

- 任一 change occurrence 的 ID 在整个 projection 中出现超过一次时，是否阻断 change verdict；建议阻断。
- duplicate 完全发生在 change 外时，仅进入 store report。
- unidentified 是否只在上述 change occurrence 来源中阻断；建议如此，避免使用含混的“delta 内”。

### REQ-3：store report 丢失了 state A 中的三类问题

描述：

B2 只要求 store report 输出 `UNBOUND`、true-`ORPHAN`、unattributed failures，但 state A 的全局判定还包含：

- `BOUND-RED`
- duplicate scenario IDs
- `UNIDENTIFIED`

特别是 B1/AC5 要求其他 change 的 red 不影响当前 change；如果 store report 又不列 `BOUND-RED`，该失败会从所有输出中消失。范围外 duplicate 和 unidentified 也存在同样问题。

风险：

这不是单纯展示调整，而是未声明的信息丢失。用户可能看到当前 change 为 GREEN，同时看不到导致测试进程失败的外部 `BOUND-RED`，也无法解释非零的 `exec.status`。

建议修复：

定义 store report 为“整个 projection 与同一 TAP 结果的完整信息性 evaluation”，至少包含：

- `boundRed`
- `unbound`
- true-`orphan`
- `unidentified`
- `unattributedFailures`
- `duplicates`

明确 `boundGreen` 是否只显示计数或完全省略。为每类规定 count、list、排序和 human 输出截断规则。新增验收：范围外 tagged red、范围外 duplicate、范围外 unidentified 均不阻断 change verdict，但必须出现在 store report。

### REQ-4：human、JSON、module API 和 gate 输出契约尚未定稿

描述：

Q1 仍在二选一，B2 也只说“新增结构化字段”。当前 state A 的兼容表面不止 CLI：

- `verify()` 的 `run.verdict`、`duplicates`、`results`、`fileCount`、`scenarioCount`
- `verifyJson()` 的既有顶层字段和 `projection`
- `formatReport()` 的单 verdict 输入
- `gate.checkBinding()` 对 `run.verdict` 和 `run.duplicates` 的直接消费
- gate JSON 的 `checks[].detail`

尚未声明 GREEN、GAPS、ERROR 三类结果中哪些新字段恒定存在，也未定义 C1 的 store summary 是 detail 文本还是结构化属性。

风险：

AI 必须自行发明数据模型；即使 CLI exit code正确，也可能破坏现有 module consumer、JSON consumer 或 gate JSON。

建议修复：

在需求中钉死一个 schema。建议采用：

- `--change` 的既有顶层 `clean/result` 及 binding arrays 改为 change 语义，并在 CHANGELOG 明确行为变化；
- 新增稳定的 `storeReport` object，承载 REQ-3 的完整分类；
- `projection` 的现有形状保持不变；
- 明确 `specFiles`、`duplicates`、`results`、`scenarioCount` 分别属于 change 还是完整 projection；
- ERROR 时明确 `change`/`storeReport` 是空结构、partial 结构还是省略；
- 定义 human 两段的稳定标题和唯一最终 `RESULT`；
- 定义 gate C1 的固定 detail 格式；如新增结构化摘要，给出准确字段；
- 给 `verify()` run object、`verifyJson()` 和 gate JSON 各提供一个完整示例。

## 维度 2：边界与异常路径是否覆盖

结论：不通过。已有 projection、TAP、非法 `id-pattern` 等 infra ERROR 继承声明，但缺少 REQ-5、REQ-6、REQ-7 所述边界。

### REQ-5：范围外失败与非零测试进程状态的关系未裁定，并冲突于 state A

描述：

state A 的有效决策 D-SR-x 明确规定“a non-zero exec status never exits 0”。目标 B 和 AC5 又要求其他 change 的 red 不影响当前 C1。实际 TAP runner 通常会在任何 `not ok` 出现时返回非零，因此以下状态会同时发生：

- 当前 change 全 green；
- 存在范围外 tagged red 或 unattributed failure；
- `exec.status !== 0`；
- TAP 本身可信，且该非零状态能被范围外失败解释。

按目标意图应为 change GREEN；按 D-SR-x 必须不能 exit 0。Q2 只讨论 unattributed 的归属，没有裁定 process status。

风险：

实现可能返回 GREEN exit 0、GAPS exit 1 或 ERROR exit 2，三种结果都有文本依据。AC1 没有钉死 fixture 的进程状态，因此也无法捕获该分歧。

建议修复：

显式 supersede 或保留 D-SR-x。若选择支持独立变绿，建议规定：

> 仅对 `verify --change`，当 `exec.status !== 0` 可由已解析的范围外失败完整解释、TAP 无 infra error、且 change verdict clean 时，允许 GREEN exit 0；若非零状态没有任何已解析失败解释，仍按现有规则 ERROR exit 2。

AC1 和 AC5 的命令必须显式 `process.exit(1)`，并断言当前 change 仍为 GREEN/C1 pass；另加“非零且无 parsed failure”仍 ERROR 的反例。CHANGELOG 和 truth decision 必须明确 D-SR-x 在 `--change` 下被限定或 superseded。

### REQ-6：零场景 change scope 的 vacuous 语义未定义

描述：

以下合法投影可能产生空 change scope：

- change 只有 `REMOVED`；
- `MODIFIED` 删除目标块的全部场景；
- `RENAMED` 的目标 Requirement 没有场景；
- `ADDED`/`MODIFIED` 块只有 unidentified 场景；
- change scope 为空，但 projection 中仍有其他 store 场景；
- 删除最后一个场景后，整个 projection 也为零场景。

state A 的 D-SR-1 要求 vacuous run 不得 GREEN，但该规则目前检查的是整个 projection，不是新的 change scope。

风险：

remove-only change 可能被意外判 GREEN，也可能因“零 change 场景”被判 ERROR；两者都会影响归档 gate，且现有 AC 没有 oracle。

建议修复：

增加零范围真值表，分别指定 GREEN/GAPS/ERROR。至少覆盖：

- 空 change scope、非空 projection；
- 空 change scope、空 projection；
- 只有 scoped unidentified；
- removal-only 且存在 lingering test。

同时声明这是沿用还是限定 D-SR-1。

### REQ-7：两视角是否共享一次 projection 和一次 TAP 执行没有成为可测试契约

描述：

B2 的“同一次运行”可以理解为一个 CLI invocation，但没有明确禁止为了 change verdict 和 store report 各执行一次测试。state A 明确是一个 test-command invocation。若执行两次，测试可能有副作用、flaky 结果或并发状态变化，两段报告也可能依据不同快照。

风险：

新增一个信息性报告可能把测试执行次数翻倍，产生未声明 side effect；change verdict 与 store report 还可能相互矛盾。

建议修复：

明确规定：

- 每次 `verify --change` 只调用一次 `buildProjection`、一次 `runTestCommand`、一次 TAP parse；
- 两个视角共享同一份内存 projection、同一 resolved matcher 和同一 TAP 结果；
- test command 执行期间发生的 spec/delta 并发修改不进入本次结果，下次运行才可见；
- projection/matcher 的 pre-test ERROR 不执行 test command；
- test command 的副作用不可 rollback，保持 state A；
- 不新增 test-command timeout；config-origin matcher 的既有 `2000ms` timeout 保持不变。

增加一个带计数器的验收测试，断言两段报告只触发一次 test command。

## 维度 3：是否存在 implied but undeclared 的状态变化或副作用

## 维度 4：每条 acceptance criterion 是否可写成 if/then oracle

需求 B1 写“`RENAMED` 取改名后的 ID”，AC3 又要求“`RENAMED` 后按新 ID 要求”。但 state A 中 `RENAMED` 的语法是 `Old Requirement -> New Requirement`，重命名的是 Requirement 名称；`archive-merge.merge()` 保留整个块内容，场景 ID 不会变化。现有测试 SR-19 也明确断言 `RENAMED` 后 `XA-01` 保持不变。

风险：

AI 无法判断应该：

- 沿用现有语法，仅将改名后 Requirement 块中的原场景 ID 纳入 change scope；
- 自动改写场景 ID；
- 还是把场景 ID 改名视为另一个 `MODIFIED` 操作。

不同选择会产生不同的 change verdict，并可能破坏 archive/project 一致性。

建议修复：

明确规定：`RENAMED` 只重命名 Requirement；change scope 包含改名后目标 Requirement 块在 projection 中的场景，场景 ID 原样保留。将 AC3 的 oracle 改成类似：

> 如果 `Alpha -> Gamma`，且原块含 `XA-01`，则 projection 中 `Gamma` 的 `XA-01` 属于 change scope；不会凭空产生新场景 ID。场景 ID 的改变必须由 `MODIFIED` 块显式表达。

### REQ-2：change scope 使用“ID 集”定义，无法确定 duplicate 和 unidentified 的边界

描述：

B1 将 change scope 定义为场景 ID 集，但以下判定依赖“场景 occurrence 的来源”，不能只靠 ID 集完成：

- change 中的场景与未修改 store 场景使用同一个 ID；
- duplicate 的两个 occurrence 都在 change 中；
- duplicate 完全发生在 change 外；
- 未识别场景位于 `ADDED`、`MODIFIED`、`REMOVED` 或未修改 store 中；
- `ADDED`/`MODIFIED` 命中 state A 的 idempotent `unchanged` 路径。

“change 范围内无 duplicate”和“delta 内无 unidentified”也不是同一个边界：前者描述 projection，后者描述原始 delta。

风险：

实现可能先把 projection 压成 `Map<ID,...>`，丢失 provenance，随后无法可靠判断 duplicate/unidentified 是否应进入 change verdict。尤其是“一个 changed occurrence 与一个 unchanged occurrence 撞 ID”可能被不同实现判成 GREEN 或 GAPS。

建议修复：

把 change scope 定义为带 provenance 的 scenario occurrence 集，再派生 ID 集。补充操作真值表：

- `ADDED`：目标 Requirement 在 projection 中的全部 scenario occurrences；
- `MODIFIED`：替换后目标块中的全部 scenario occurrences，包括保留的旧 ID；
- `REMOVED`：不贡献 scenario occurrence；
- `RENAMED`：改名后目标块中的全部 occurrence，ID 不变；
- idempotent `unchanged`：是否仍贡献 scope，必须明确。

同时明确：

- 任一 change occurrence 的 ID 在整个 projection 中出现超过一次时，是否阻断 change verdict；建议阻断。
- duplicate 完全发生在 change 外时，仅进入 store report。
- unidentified 是否只在上述 change occurrence 来源中阻断；建议如此，避免使用含混的“delta 内”。

### REQ-3：store report 丢失了 state A 中的三类问题

描述：

B2 只要求 store report 输出 `UNBOUND`、true-`ORPHAN`、unattributed failures，但 state A 的全局判定还包含：

- `BOUND-RED`
- duplicate scenario IDs
- `UNIDENTIFIED`

特别是 B1/AC5 要求其他 change 的 red 不影响当前 change；如果 store report 又不列 `BOUND-RED`，该失败会从所有输出中消失。范围外 duplicate 和 unidentified 也存在同样问题。

风险：

这不是单纯展示调整，而是未声明的信息丢失。用户可能看到当前 change 为 GREEN，同时看不到导致测试进程失败的外部 `BOUND-RED`，也无法解释非零的 `exec.status`。

建议修复：

定义 store report 为“整个 projection 与同一 TAP 结果的完整信息性 evaluation”，至少包含：

- `boundRed`
- `unbound`
- true-`orphan`
- `unidentified`
- `unattributedFailures`
- `duplicates`

明确 `boundGreen` 是否只显示计数或完全省略。为每类规定 count、list、排序和 human 输出截断规则。新增验收：范围外 tagged red、范围外 duplicate、范围外 unidentified 均不阻断 change verdict，但必须出现在 store report。

### REQ-4：human、JSON、module API 和 gate 输出契约尚未定稿

描述：

Q1 仍在二选一，B2 也只说“新增结构化字段”。当前 state A 的兼容表面不止 CLI：

- `verify()` 的 `run.verdict`、`duplicates`、`results`、`fileCount`、`scenarioCount`
- `verifyJson()` 的既有顶层字段和 `projection`
- `formatReport()` 的单 verdict 输入
- `gate.checkBinding()` 对 `run.verdict` 和 `run.duplicates` 的直接消费
- gate JSON 的 `checks[].detail`

尚未声明 GREEN、GAPS、ERROR 三类结果中哪些新字段恒定存在，也未定义 C1 的 store summary 是 detail 文本还是结构化属性。

风险：

AI 必须自行发明数据模型；即使 CLI exit code正确，也可能破坏现有 module consumer、JSON consumer 或 gate JSON。

建议修复：

在需求中钉死一个 schema。建议采用：

- `--change` 的既有顶层 `clean/result` 及 binding arrays 改为 change 语义，并在 CHANGELOG 明确行为变化；
- 新增稳定的 `storeReport` object，承载 REQ-3 的完整分类；
- `projection` 的现有形状保持不变；
- 明确 `specFiles`、`duplicates`、`results`、`scenarioCount` 分别属于 change 还是完整 projection；
- ERROR 时明确 `change`/`storeReport` 是空结构、partial 结构还是省略；
- 定义 human 两段的稳定标题和唯一最终 `RESULT`；
- 定义 gate C1 的固定 detail 格式；如新增结构化摘要，给出准确字段；
- 给 `verify()` run object、`verifyJson()` 和 gate JSON 各提供一个完整示例。

## 维度 2：边界与异常路径是否覆盖

结论：不通过。已有 projection、TAP、非法 `id-pattern` 等 infra ERROR 继承声明，但缺少 REQ-5、REQ-6、REQ-7 所述边界。

### REQ-5：范围外失败与非零测试进程状态的关系未裁定，并冲突于 state A

描述：

state A 的有效决策 D-SR-x 明确规定“a non-zero exec status never exits 0”。目标 B 和 AC5 又要求其他 change 的 red 不影响当前 C1。实际 TAP runner 通常会在任何 `not ok` 出现时返回非零，因此以下状态会同时发生：

- 当前 change 全 green；
- 存在范围外 tagged red 或 unattributed failure；
- `exec.status !== 0`；
- TAP 本身可信，且该非零状态能被范围外失败解释。

按目标意图应为 change GREEN；按 D-SR-x 必须不能 exit 0。Q2 只讨论 unattributed 的归属，没有裁定 process status。

风险：

实现可能返回 GREEN exit 0、GAPS exit 1 或 ERROR exit 2，三种结果都有文本依据。AC1 没有钉死 fixture 的进程状态，因此也无法捕获该分歧。

建议修复：

显式 supersede 或保留 D-SR-x。若选择支持独立变绿，建议规定：

> 仅对 `verify --change`，当 `exec.status !== 0` 可由已解析的范围外失败完整解释、TAP 无 infra error、且 change verdict clean 时，允许 GREEN exit 0；若非零状态没有任何已解析失败解释，仍按现有规则 ERROR exit 2。

AC1 和 AC5 的命令必须显式 `process.exit(1)`，并断言当前 change 仍为 GREEN/C1 pass；另加“非零且无 parsed failure”仍 ERROR 的反例。CHANGELOG 和 truth decision 必须明确 D-SR-x 在 `--change` 下被限定或 superseded。

### REQ-6：零场景 change scope 的 vacuous 语义未定义

描述：

以下合法投影可能产生空 change scope：

- change 只有 `REMOVED`；
- `MODIFIED` 删除目标块的全部场景；
- `RENAMED` 的目标 Requirement 没有场景；
- `ADDED`/`MODIFIED` 块只有 unidentified 场景；
- change scope 为空，但 projection 中仍有其他 store 场景；
- 删除最后一个场景后，整个 projection 也为零场景。

state A 的 D-SR-1 要求 vacuous run 不得 GREEN，但该规则目前检查的是整个 projection，不是新的 change scope。

风险：

remove-only change 可能被意外判 GREEN，也可能因“零 change 场景”被判 ERROR；两者都会影响归档 gate，且现有 AC 没有 oracle。

建议修复：

增加零范围真值表，分别指定 GREEN/GAPS/ERROR。至少覆盖：

- 空 change scope、非空 projection；
- 空 change scope、空 projection；
- 只有 scoped unidentified；
- removal-only 且存在 lingering test。

同时声明这是沿用还是限定 D-SR-1。

### REQ-7：两视角是否共享一次 projection 和一次 TAP 执行没有成为可测试契约

描述：

B2 的“同一次运行”可以理解为一个 CLI invocation，但没有明确禁止为了 change verdict 和 store report 各执行一次测试。state A 明确是一个 test-command invocation。若执行两次，测试可能有副作用、flaky 结果或并发状态变化，两段报告也可能依据不同快照。

风险：

新增一个信息性报告可能把测试执行次数翻倍，产生未声明 side effect；change verdict 与 store report 还可能相互矛盾。

建议修复：

明确规定：

- 每次 `verify --change` 只调用一次 `buildProjection`、一次 `runTestCommand`、一次 TAP parse；
- 两个视角共享同一份内存 projection、同一 resolved matcher 和同一 TAP 结果；
- test command 执行期间发生的 spec/delta 并发修改不进入本次结果，下次运行才可见；
- projection/matcher 的 pre-test ERROR 不执行 test command；
- test command 的副作用不可 rollback，保持 state A；
- 不新增 test-command timeout；config-origin matcher 的既有 `2000ms` timeout 保持不变。

增加一个带计数器的验收测试，断言两段报告只触发一次 test command。
