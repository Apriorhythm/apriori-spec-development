# 下载/桌面自动整理工具 — 设计文档

日期:2026-07-08
状态:已获用户批准

## 目标

自动整理 Windows 11 上的下载文件夹和桌面:首次运行清理现有的数千个积压文件,之后由 Windows 任务计划程序每天自动运行一次,只处理增量。

## 核心原则:宁可漏整理,绝不误伤

- **只移动,永不删除**。包括重复文件——挪进隔离区,不删。
- **永不覆盖**。目标位置存在同名文件时自动加序号(如 `报告(1).pdf`)。
- **每一步可撤销**。所有移动先写日志再执行,可整批撤回。
- **不确定就跳过**。单个文件处理失败不中断整批。

## 监控范围

- 下载文件夹(如 `C:\Users\<用户>\Downloads`)
- 桌面(如 `C:\Users\<用户>\Desktop`)
- 范围实现为文件夹列表,后续可扩展。

## 整理规则(按优先级依次匹配,命中即停)

1. **下载中的临时文件**(扩展名 `.crdownload`、`.part`、`.tmp`)→ 跳过,不碰。
2. **重复文件**:按文件内容 SHA-256 哈希对比,内容完全相同视为重复;保留修改时间最早的一份为原件,其余副本移入 `_重复文件/`。
3. **旧压缩包**:类型为压缩包且超过 180 天未被使用 → 移入 `_旧文件/`。判定取最后访问时间与修改时间中较新者(Windows 上访问时间可能未启用,以两者较新为准可避免误判为"旧")。
4. **按类型 + 月份归档**:其余文件移入 `类型/年-月/` 子文件夹,月份取文件修改时间。类型分为:
   - `图片/`(jpg、png、gif、webp、svg、heic 等)
   - `视频/`(mp4、mkv、avi、mov 等)
   - `文档/`(pdf、docx、xlsx、pptx、txt、md 等)
   - `压缩包/`(zip、rar、7z、tar、gz 等)
   - `安装包/`(exe、msi、msix 等)
   - `其他/`(未匹配任何类型的文件)

补充规则:

- **原地建子文件夹**:所有分类子文件夹建在各自的源文件夹内(下载、桌面各一套),`_旧文件/` 与 `_重复文件/` 同理。
- **工具自建的文件夹不再被整理**(防止反复搬运)。
- 只处理源文件夹顶层的文件,不递归进入用户已有的子文件夹。

## 使用形态

单个 Python 脚本(标准库为主),四个子命令:

| 命令 | 行为 |
| --- | --- |
| `preview` | 打印完整的"原路径 → 新路径"清单,不移动任何文件 |
| `run` | 执行整理;每次运行生成一份 JSON 日志,逐条记录每个文件的原路径与新路径 |
| `undo` | 读取最近一次(或用 `--log` 指定某次)日志,将文件整批移回原位 |
| `schedule` | 在 Windows 任务计划程序中注册每日一次的 `run` 任务 |

**首次使用流程**:`preview` → 用户人工核对清单 → `run` 完成首次大扫除 → `schedule` 挂上每日任务。日常增量由计划任务自动 `run`,发现问题随时 `undo`。

## 数据流

1. 扫描监控文件夹顶层文件 → 逐个匹配规则 → 生成移动计划(内存中)。
2. `preview`:打印计划,结束。
3. `run`:先把计划整体写入日志文件(`logs/整理日志-<时间戳>.json`),再逐条执行移动;每条执行结果(成功/失败原因)回写日志。
4. `undo`:读日志,按"新路径 → 原路径"逆向移动。

## 错误处理

- 单个文件失败(被占用、无权限、路径过长等):记录原因、跳过、继续处理其余文件;结束时汇总报告。
- 日志先写后挪:即使中途断电/中断,已执行的移动都有记录,`undo` 仍可用。
- `undo` 时原位置已被占用:跳过该文件并在报告中列出,不覆盖。
- 哈希计算失败的文件:视为不重复,走普通类型归档(宁可漏整理)。

## 测试

在临时文件夹中构造测试文件,覆盖:

- 各类型文件归入正确的 `类型/年-月/` 文件夹;
- 内容相同的重复文件:最早一份留在原分类,其余进 `_重复文件/`;
- 超过 180 天未访问的压缩包进 `_旧文件/`;
- 同名冲突自动加序号,原文件不被覆盖;
- 临时下载文件、用户已有子文件夹、工具自建文件夹均不被触碰;
- `preview` 输出与 `run` 实际动作一致;
- `run` 后执行 `undo`,目录状态与整理前完全一致。

## 明确不做(YAGNI)

- 不删除任何文件(重复文件也只隔离)。
- 不做实时监控(每日定时已满足需求)。
- 不递归整理用户已有的子文件夹。
- 不做 GUI;命令行 + 计划任务足够。
