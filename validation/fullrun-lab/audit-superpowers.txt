    58	3. **管理页 `/admin/:adminToken`**：同结果视图 + "关闭投票"按钮（关闭后按钮变为

    62	
    63	`data/polls.json`——单个 JSON 对象，poll id 做 key：
    64	
    65	```json
    66	{
    67	  "a1b2c3": {
    68	    "id": "a1b2c3",
    69	    "adminToken": "x9y8z7w6q5r4t3s2",
    70	    "question": "周五团建去哪",
    71	    "options": ["烤肉", "火锅", "轰趴馆"],
    72	    "multiple": false,
    73	    "deadline": "2026-07-10T18:00:00+08:00",
    74	    "closed": false,
    75	    "votes": [[0], [2], [1]],
    76	    "createdAt": "2026-07-07T10:00:00+08:00"
    77	  }
    78	}
    79	```
    80	
    81	- `id`：6 位随机字母数字（URL 友好）；`adminToken`：16 位随机。均用 `crypto`
    82	  的安全随机生成，互不可推导。
    83	- `votes`：每次投票记录一个"所选选项下标"数组（单选即单元素数组）。保留原始
    84	  记录，票数由 `polls.js` 现算。
    85	- `deadline` 可为 `null`。**可投状态** = `!closed && (deadline 为 null || now < deadline)`。
    86	- 持久化：写临时文件再 `rename`，防止进程中断损坏数据文件。
    87	- 启动时数据文件不存在→从空数据开始；文件损坏（JSON 解析失败）→将原文件备份为
    88	  `polls.json.bak-<时间戳>` 后从空数据开始，不悄悄丢弃。

    90	## 6. API
    91	
    92	全部返回 JSON。页面路由 `/poll/:id`、`/admin/:token` 返回对应 HTML，页面自行从
    93	URL 提取 id/token 调 API。
    94	
    95	| 方法 | 路径 | 作用 | 成功返回 |
    96	|---|---|---|---|
    97	| POST | `/api/polls` | 建投票 | `{id, adminToken}` |
    98	| GET | `/api/polls/:id` | 投票详情 + 计票（公开视图，**不含 adminToken**） | 公开字段 + `counts`、`total`、`open` |
    99	| POST | `/api/polls/:id/vote` | 投票，body `{choices:[下标...]}` | 更新后的公开视图 |
   100	| GET | `/api/admin/:adminToken` | 管理视图 | 与公开视图同款字段 |
   101	| POST | `/api/admin/:adminToken/close` | 关闭投票 | 更新后的管理视图 |
   102	
   103	公开视图字段：`id, question, options, multiple, deadline, closed, open, counts, total`。
   104	`counts` 为与 `options` 等长的计票数组；`total` 为投票人次；`open` 为当前可投状态。
   105	
   106	## 7. 校验与错误处理
   107	
   108	校验统一在 `polls.js`，出错抛带 `status` 与中文 `message` 的错误；`server.js`
   109	统一转成 `{"error": "<消息>"}` 响应，前端直接展示消息。
   110	
   111	建投票（400）：
   112	
   113	- 问题：去空白后非空，≤200 字符
   114	- 选项：逐行去空白、丢弃空行后 ≥2 个且 ≤20 个，每个 ≤100 字符
   115	- deadline：可省略；给了必须能被 `Date` 解析且晚于当前时间
   116	
   117	投票：
   118	
   119	- 404：poll 不存在
   120	- 409：投票已关闭 / 已过截止时间（消息区分两种原因）
   121	- 400：`choices` 缺失或为空、含非法下标、含重复下标；单选却提交多个选项
   122	
   123	其他：未知 API 路径 404；请求体非法 JSON 400；`GET /api/admin/:token` token 不存在 404。
   124	
   125	并发：Node 单线程 + 内存单例 store，请求逐个处理，写文件串行化，无覆盖问题。
   126	截止时间不用定时器：每次读取现算是否过期。

   272	```js
   273	'use strict';
   274	const crypto = require('node:crypto');
   275	
   276	class PollError extends Error {
   277	  constructor(status, message) {
   278	    super(message);
   279	    this.status = status;
   280	  }
   281	}
   282	
   283	const ID_CHARS = 'abcdefghjkmnpqrstuvwxyz23456789';
   284	
   285	function randomId(length) {
   286	  const bytes = crypto.randomBytes(length);
   287	  let out = '';
   288	  for (let i = 0; i < length; i++) out += ID_CHARS[bytes[i] % ID_CHARS.length];
   289	  return out;
   290	}
   291	
   292	function createPolls(store, now = () => new Date()) {
   293	  function create(input) {
   294	    const question = String(input.question ?? '').trim();
   295	    if (!question) throw new PollError(400, '问题不能为空');
   296	    if (question.length > 200) throw new PollError(400, '问题不能超过 200 字');
   297	
   298	    const raw = Array.isArray(input.options) ? input.options : [];
   299	    const options = raw.map((o) => String(o).trim()).filter(Boolean);
   300	    if (options.length < 2) throw new PollError(400, '至少需要 2 个选项');
   301	    if (options.length > 20) throw new PollError(400, '选项不能超过 20 个');
   302	    if (options.some((o) => o.length > 100)) throw new PollError(400, '单个选项不能超过 100 字');
   303	
   304	    let deadline = null;
   305	    if (input.deadline) {
   306	      const d = new Date(input.deadline);
   307	      if (Number.isNaN(d.getTime())) throw new PollError(400, '截止时间格式不正确');
   308	      if (d <= now()) throw new PollError(400, '截止时间必须晚于当前时间');
   309	      deadline = d.toISOString();
   310	    }
   311	
   312	    const poll = {
   313	      id: randomId(6),
   314	      adminToken: randomId(16),
   315	      question,
   316	      options,
   317	      multiple: Boolean(input.multiple),
   318	      deadline,
   319	      closed: false,
   320	      votes: [],
   321	      createdAt: now().toISOString(),
   322	    };
   323	    store.put(poll);
   324	    return poll;
   325	  }
   326	
   327	  return { create };
   328	}
   329	
   330	module.exports = { createPolls, PollError };
   331	```

   451	  }

   461	      multiple: poll.multiple,

   471	    const poll = store.get(id);
   472	    if (!poll) throw new PollError(404, '投票不存在');

   474	  }

   489	      throw new PollError(400, '选项不合法');
   490	    }
   491	    if (!poll.multiple && choices.length > 1) {
   492	      throw new PollError(400, '该投票为单选，只能选择一个选项');
   493	    }
   494	    poll.votes.push(choices);
   495	    store.put(poll);
   496	    return view(poll);
   497	  }

   501	    for (const id of Object.keys(all)) {

   504	    throw new PollError(404, '管理链接不存在');

   514	    store.put(poll);
   515	    return view(poll);
   516	  }

   665	```js
   666	'use strict';
   667	const http = require('node:http');
   668	const fs = require('node:fs');
   669	const path = require('node:path');
   670	const { createStore } = require('./lib/store');
   671	const { createPolls, PollError } = require('./lib/polls');
   672	
   673	const PUBLIC_DIR = path.join(__dirname, 'public');
   674	
   675	function sendJson(res, status, body) {
   676	  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
   677	  res.end(JSON.stringify(body));
   678	}
   679	
   680	function sendFile(res, name, type) {
   681	  res.writeHead(200, { 'Content-Type': `${type}; charset=utf-8` });
   682	  res.end(fs.readFileSync(path.join(PUBLIC_DIR, name)));
   683	}
   684	
   685	function readJsonBody(req) {
   686	  return new Promise((resolve, reject) => {
   687	    let raw = '';
   688	    req.on('data', (chunk) => {
   689	      raw += chunk;
   690	      if (raw.length > 1e6) req.destroy();
   691	    });
   692	    req.on('end', () => {
   693	      try {
   694	        resolve(raw ? JSON.parse(raw) : {});
   695	      } catch {
   696	        reject(new PollError(400, '请求格式不正确'));
   697	      }
   698	    });
   699	    req.on('error', reject);
   700	  });
   701	}
   702	
   703	function createServer(dataDir) {
   704	  const store = createStore(dataDir);
   705	  const polls = createPolls(store);
   706	
   707	  return http.createServer(async (req, res) => {
   708	    const { pathname } = new URL(req.url, 'http://localhost');
   709	    const get = req.method === 'GET';
   710	    const postReq = req.method === 'POST';
   711	    let m;
   712	    try {
   713	      if (get && pathname === '/') return sendFile(res, 'index.html', 'text/html');
   714	      if (get && pathname === '/style.css') return sendFile(res, 'style.css', 'text/css');
   715	      if (get && /^\/poll\/[a-z2-9]+$/.test(pathname)) return sendFile(res, 'poll.html', 'text/html');
   716	      if (get && /^\/admin\/[a-z2-9]+$/.test(pathname)) return sendFile(res, 'admin.html', 'text/html');
   717	
   718	      if (postReq && pathname === '/api/polls') {
   719	        const body = await readJsonBody(req);
   720	        const poll = polls.create(body);
   721	        return sendJson(res, 201, { id: poll.id, adminToken: poll.adminToken });
   722	      }
   723	      if (get && (m = pathname.match(/^\/api\/polls\/([a-z2-9]+)$/))) {
   724	        return sendJson(res, 200, polls.getView(m[1]));
   725	      }
   726	      if (postReq && (m = pathname.match(/^\/api\/polls\/([a-z2-9]+)\/vote$/))) {
   727	        const body = await readJsonBody(req);
   728	        return sendJson(res, 200, polls.vote(m[1], body.choices));
   729	      }
   730	      if (get && (m = pathname.match(/^\/api\/admin\/([a-z2-9]+)$/))) {
   731	        return sendJson(res, 200, polls.adminView(m[1]));
   732	      }
   733	      if (postReq && (m = pathname.match(/^\/api\/admin\/([a-z2-9]+)\/close$/))) {
   734	        const body = await readJsonBody(req);
   735	        void body;
   736	        return sendJson(res, 200, polls.close(m[1]));
   737	      }
   738	      return sendJson(res, 404, { error: '页面不存在' });
   739	    } catch (err) {
   740	      if (err instanceof PollError) return sendJson(res, err.status, { error: err.message });
   741	      console.error(err);
   742	      return sendJson(res, 500, { error: '服务器内部错误' });
   743	    }
   744	  });
   745	}
   746

   748

   752	    console.log(`快速投票已启动: http://localhost:${port}`);
   753	  });
   754	}
