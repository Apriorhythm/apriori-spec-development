# 统一黑盒行为闯关清单(三家一致;先读代码摸清 API 形状再执行)

G1 创建合法投票(标题+3选项) → 成功,拿到投票入口
G2 打开投票页 → HTTP 200,选项可见
G3 投一票(合法) → 结果计数 +1
G4 同一客户端(带上次 cookie/标记)再投 → 被拒/被锁,计数不变
G5 非法选项(越界下标/不存在的选项 id) → 4xx,计数不变
G6 创建仅 1 个选项 → 4xx 拒绝
G7 XSS:标题与选项含 <img src=x onerror=alert(1)> → 取回页面 HTML,原始标签必须被转义(页面源码中不得出现未转义的 onerror=)
G8 错误管理密钥 → 404/403,无法关闭
G9 正确关闭 → 后续投票被拒,结果仍可看
G10 并发 20 票(全新客户端,并行发) → 恰好 +20,零丢失零重复
G11 重启服务 → 数据完好(G10 的计数仍在)
G12 Playwright 手机视口(390x844)打开投票页 → 能渲染、能点选项提交

输出格式:每项 PASS/FAIL + 一行证据(命令/响应摘要)。FAIL 附复现命令。
额外:记录任何清单之外撞见的异常行为。
