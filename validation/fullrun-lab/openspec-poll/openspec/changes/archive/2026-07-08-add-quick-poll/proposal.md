# Proposal: add-quick-poll

## Why

开会或群聊里临时征集意见时，现有投票工具要么要求登录/注册，要么依赖特定平台（微信小程序、企业 IM 插件）。需要一个零门槛的网页投票小工具：发起人几秒建好投票、发一条链接，参与者点开即投、匿名免登录，所有人共享同一份实时结果。本仓库当前为空项目，这是首个变更，从零建立该工具。

## What Changes

- 新增投票创建：标题 + 2 个及以上选项，可选"单选/多选"模式（多选可限制最多可选项数），可选截止时间。
- 新增双链接机制：创建成功后生成参与链接（公开分享）与管理链接（含随机管理密钥，仅展示一次，供发起人使用）。
- 新增匿名投票：参与者免登录提交选择；浏览器本地记录"已投过"实现软防重（同一浏览器重复打开直接显示结果）。
- 新增结果页：展示各选项票数与比例，刷新即见最新结果。
- 新增投票关闭：发起人通过管理链接手动关闭投票；到达截止时间自动视为关闭。关闭后仅可查看结果，不可再投。
- 新增文件存储：每个投票一个 JSON 文件，进程内串行化写入 + 原子写（临时文件 + rename），不引入数据库。

## Capabilities

### New Capabilities

- `poll-creation`: 创建投票（标题、选项、单选/多选、可选截止时间），生成投票 ID、参与链接与管理密钥。
- `poll-voting`: 匿名提交投票（单选/多选校验、软防重、开放状态校验），共享计票。
- `poll-results`: 查看投票结果（票数、比例、投票状态），对所有持参与链接者可见。
- `poll-lifecycle`: 投票的开放/关闭状态管理（管理链接手动关闭、截止时间自动关闭）。
- `poll-storage`: 基于 JSON 文件的持久化（每投票一文件、写串行化、原子写）。

### Modified Capabilities

（无——空项目，无既有 spec。）

## Impact

- 全新代码：一个 Node.js HTTP 服务（含路由、页面、静态资源）、`data/` 目录下的 JSON 存储文件。
- 新增依赖：预期仅极少量运行时依赖（详见 design.md），不引入数据库。
- 无既有代码、API 或系统受影响（空仓库）。
