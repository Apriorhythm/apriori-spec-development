# poll-creation Specification

## Purpose

定义投票的创建：输入校验、投票 ID 与双链接（参与/管理）的生成规则。

## Requirements

### Requirement: 创建投票
系统必须（SHALL）允许任何访问者免登录创建投票。创建输入为：标题（必填，非空，≤200 字符）、选项列表（必填，2~20 个，每项非空且 ≤100 字符）、投票模式（单选或多选，默认单选）、多选上限（仅多选模式下有效，可选，2 ≤ 上限 ≤ 选项数，不填表示不限）、截止时间（可选，必须晚于当前时间）。

#### Scenario: 成功创建单选投票
- **WHEN** 访问者提交标题"午饭吃什么"与选项 ["面", "饭", "饺子"]，模式为单选
- **THEN** 系统创建投票并返回创建成功页

#### Scenario: 成功创建带截止时间的多选投票
- **WHEN** 访问者提交合法标题、3 个选项、模式为多选（上限 2）、截止时间为未来时刻
- **THEN** 系统创建投票，记录模式、多选上限与截止时间

#### Scenario: 选项不足被拒绝
- **WHEN** 访问者提交的有效选项少于 2 个（空白选项不计入）
- **THEN** 系统必须拒绝创建并提示"至少需要 2 个选项"，不产生任何存储文件

#### Scenario: 截止时间早于当前时间被拒绝
- **WHEN** 访问者提交的截止时间不晚于当前时间
- **THEN** 系统必须拒绝创建并提示截止时间无效

### Requirement: 投票 ID 与双链接生成
创建成功时，系统必须（SHALL）生成不可预测的投票 ID（URL 安全字符，≥6 字符）与不可预测的管理密钥（≥16 字符随机值），并在创建成功页一次性展示两个链接：参与链接 `/p/<id>` 与管理链接 `/p/<id>/admin/<管理密钥>`。管理密钥必须仅存在于存储文件与管理链接中，绝不出现在参与链接或结果页。

#### Scenario: 创建成功页展示双链接
- **WHEN** 投票创建成功
- **THEN** 页面同时展示参与链接与管理链接，并提示发起人：管理链接仅此一次展示，请自行保存

#### Scenario: 参与页不泄露管理密钥
- **WHEN** 任何人打开参与链接或结果页
- **THEN** 响应内容中必须不包含管理密钥
