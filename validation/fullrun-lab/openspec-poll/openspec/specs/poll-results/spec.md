# poll-results Specification

## Purpose

定义结果查看：票数与占比展示、状态标识、不存在投票的处理。

## Requirements

### Requirement: 结果查看
系统必须（SHALL）向任何持参与链接者提供结果页 `/p/<id>/results`，展示：投票标题、每个选项的票数与占比（以总提交人数为分母；总数为 0 时占比显示 0%）、总提交人数、投票状态（进行中/已结束）。结果不要求登录即可查看，且每次加载必须反映当前最新计票。

#### Scenario: 查看进行中投票的结果
- **WHEN** 任何人打开进行中投票的结果页
- **THEN** 页面展示各选项当前票数、占比、总提交人数，状态为"进行中"

#### Scenario: 零票投票的结果
- **WHEN** 打开尚无人投票的投票结果页
- **THEN** 各选项票数为 0、占比为 0%，页面正常渲染

#### Scenario: 刷新可见最新结果
- **WHEN** 有新投票提交后，任何人刷新结果页
- **THEN** 页面展示包含新提交在内的最新票数

### Requirement: 不存在的投票返回 404
系统必须（SHALL）对不存在的投票 ID 的任何页面（参与页、结果页、管理页）返回 404 与友好提示，且必须不泄露内部错误细节。

#### Scenario: 访问不存在的投票
- **WHEN** 任何人访问 `/p/不存在的id` 或其结果页
- **THEN** 系统返回 404 与"投票不存在"提示
