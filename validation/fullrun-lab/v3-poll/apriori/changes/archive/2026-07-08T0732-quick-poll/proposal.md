# proposal — quick-poll

## WHY

开会/群里征集意见时，现有方式（口头统计、接龙、第三方投票平台）要么慢、要么要登录注册。需要一个部署在自家内网、零门槛的快速投票工具：建投票 ≤1 分钟，参与者点链接即投，结果实时可投影。

## WHAT

一个零 npm 依赖的 Node HTTP 服务 + 原生 HTML/JS 前端 + JSON 文件存储：

- **创建**：首页填标题 + 2–20 个选项 → 得到公开投票链接 + 私有管理链接（CSPRNG 密钥）。
- **投票**：匿名免登录单选；同一浏览器投过后只看结果（localStorage 防手滑）。
- **结果**：全透明，任何人随时可看；每 3 秒自动刷新，适合大屏投影。
- **关闭**：仅持管理链接可关闭（幂等）；关闭后可看不可投。
- **可靠性**：per-poll 串行化 + 临时文件-rename 原子写 —— 几十人并发不丢票，成功响应 ⇔ 已落盘。

规格全文：`specs/poll-service.md`（28 个场景）；技术方案：`design.md`。

## OUT OF SCOPE

多选、截止时间/自动关闭（schema 已预留字段）、登录/账号、防恶意刷票（只防手滑）、投票历史列表、创建后编辑、多题问卷、WebSocket 推送。理由见 `requirement/req-final.md` §6。
